把四级 LUT 变成看得见的结果

  1. 选择图片

    使用项目素材或上传图片，最大 400 万像素；1024×768 为题目图片规格。上传时按 EXIF 方向转正并转 RGB，不应用 ICC 色彩管理。

  2. 配置四级映射

    使用合成示例，或为每级上传 .lut256 完整表、.slut 模型。完整表必须是 B 最快、256³×3 字节 RGB8；已有模型不会重新拟合。

  3. 运行并比较

    拖动分割线看前后变化。误差计算比较的是稀疏结果和完整四级参考；只上传稀疏模型时没有完整参考，指标与热图将不可用。

  4. 保存结果

    结果包包含四张模型、输入/输出图片、可用的完整参考与热图、参数和来源哈希。示例是确定性的数值映射，不代表真实 ISP。

拟合在后台串行执行，最小二乘可能需要较长时间。关闭页面不会取消任务；停止本地服务会结束会话。产物保留在启动时显示的目录。
