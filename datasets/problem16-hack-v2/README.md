# hack-v2 三维、周期和四级传播扩展

本版本在 [hack-v1](../problem16-hack-v1/README.md) 之外追加 **36 个四级 LUT case**：28 个开发参数、8 个预留参数。旧生成器、源字节、阈值与留出规则不变。所有完整源输出保持 RGB8，四张源表各不相同；稀疏模型质量保持 `unmeasured`。

| 新覆盖 | 固定参数与用途 |
| --- | --- |
| 网格非中央节点 | m17 的 63.75 与 m33 的 183.28125 附近各取三个阈值，保存节点的精确有理数与相对 floor 偏移 |
| 三维局部峰谷 | `[122,90,202]` 起始的 1/2/4 码值小立方体，同时增加/减少不同通道，区别于只沿一个轴变化的窄峰 |
| 斜平面薄带 | `R+G−B` 宽 1/2/4 的窄带，观察非轴对齐支撑区域 |
| 周期三通道耦合 | `R+2G+3B` 的整数三角波，周期 4/16/64，明确依赖全部通道 |
| 分块奇偶 | 周期 1/2/4/8 的三维交替，保留为高频边界研究 |
| 半位舍入 | 两组二分之一仿射混色，固定负偏置和逐级半向上舍入约定 |
| 量化后放大 | 先除以 2/8 并压缩到窄范围，再过阶梯、放大并轴置换，每级保留 RGB8 |
| 色域折返与裁剪 | 非对角、有负系数的 CCM，分别放大跨通道硬裁剪边界 |

8 个预留参数使用不同坐标、系数、幅度或周期，以及独立 seed 标识；只有具有随机性的生成器才使用 seed 改变字节。它们是公开的预声明配置，不声称盲测或统计独立。

[catalog.json](catalog.json) 保存配方，[sources.json](sources.json) 保存完整源字节 SHA-256，[manifest.json](manifest.json) 绑定实际图片与小型模型。源表按红轴分块生成，完整大表由显式单 case 命令导出，不批量放入 Git。

新增 **21 张 1024×768 RGB8 PPM**：三张蓝轴位置不同的局部盒切片，以及斜平面、周期耦合、色域裁剪和暗部舍入分布；每个分布各有原序、重排、按颜色聚集三种布局。重排使用固定 uint32 双射键排序，布局记录同一像素多重集的哈希。

另存一份 `coupled-wave-p64` 的四级 m17 采样模型与固定探针。相对独立整数 oracle 检查所有实际编译整数后端；C99/结构化调度的第二级应选择 `tetra` 通用路径，不能误认为一维曲线。它只是有限探针回归，不等同于完整色域证明或模型精度达标。

验收沿用 [RGB 距离与分层错误口径](../problem16-hack-v1/acceptance.json)。本轮没有拟合方法矩阵、预留源精度评价、阈值调整或性能扫描。完整真值的哈希仅用于合并数据去重，不作为拟合误差统计。

```bash
python -m lutlab hackextend build
python -m lutlab hackextend export --case box-peak-w1 --output data/hack-v2
python -m lutlab dataset show --case hack-v2--box-peak-w1
```

新旧数据的共同入口和复现边界见[合并数据集](../problem16-unified-v1/README.md)。
