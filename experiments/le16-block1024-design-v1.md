# 固定1024B块的LE16 map预案

Agent：`/root/memory`。Operator：当前16题任务用户。Status：Proposed。只研究原1024B块的一个新map格式，不扫描块尺寸或参数，不改变已验M16D、默认API或其它分支。

在新导出前只读原ROM的1056B头和65536B map，实际M16D v1为block_bits10、230合法palette、10482个1024B块（不是10483），pool10733568B，原ROM10800160B、原常驻10801216B。原map最小/最大绝对偏移65536/10798080。原完整逻辑ID SHA为a020c67a0e8ce77e668e6c6d85206af53005923316b4778194637182b4cfaea0。

唯一新格式M10L v1保留1056B头及完整256槽palette，field8固定10，field12为合法palette count，field16为payload长度，其余保留字必须0。固定16384个LE16局部块ID，map32768B；pool按原字节/顺序完整复制，查询`32768 + (ID<<10) + (RGB24&1023)`。预期ROM10767392B+原1056B model=10768448B，实际必须核文件和`sizeof`。仅减少32768B，约为旧候选的0.3034%，不夸大容量收益。

缩小第一级map可能改善缓存行为，但32KiB并非“全部工作集在L1”的证明；palette、栈和其它数据仍竞争容量。新路径比原绝对offset多了shift/add，依赖层数未减少。可证伪问题是同场最劣吞吐/原1024块配对是否改善，而不是以较小map推定命中。若旧1024块本场有效低于50，保留首场通过并同步撤销跨场全情形推荐，不用旧好场次覆盖。

准备验证pool非空、1024B整块、块数不超过65536、所有LE16 ID合法、palette count1..256及pool字节小于count。块ID65535在恰好65536块时必须合法，不能错误限制为65535块。所有整数用无符号并核文件长度；C99显式LE16、无堆/浮点/端序/对齐或外部padding前提。model ABI仍1056B，借用生命周期、失败清零、out/ROM重叠无写拒绝、零长和部分重叠拒绝保持。

AVX2从原实测`memory_avx2_10.cpp`快照生成，仅改namespace与lookup：4B绝对偏移变2B局部ID及shift10，原输入/预取/输出/OMP块布局不变。C99也保持原逐像素算法，不叠加store/ILP/Clang或RGB32。map末项读2B恰好至map边界；原和强制最后map→最后pool分别把ROM真实末端贴保护页，验证尾部和最后pool，不假定用户padding。另用65536块+256合法palette的扩展正向夹具，最后map ID65535，验证252..255全部最高合法ID及末端保护。

生成后、任何导出/构建前冻结源与唯一计划，原ROM和旧DLL身份固定。离线串行重建全16MiB逻辑ID，无gold/照片选择。质量实际遍历完整256³：纯C99、桌面scalar、AVX2单/四线程各原地/分离共8配置；有限长度/非对齐/尾哨兵、非法ID/长度/保留字/地址、图像保护页、真实/强制/65535正向ROM保护页另验。

正式性能另待root排他授权，固定五角色78/80、原1024B块、新LE16 AVX2及新LE16 C99。四worker轮转/反序、1/4线程、原地/分离，每配置预热1+5完整百图；输入恢复不计时，首尾SHA验证。速度分母为每worker同场较快78/80，全部worker最劣按100/90/80/70/60/50，A/A单对0.8..1.25、中位1/1.1..1.1，失效清空对应所有档位，不补跑。旧1024只作直接配对，不能替代快速分母。

在任何源/计划冻结前，root明确选择本轮受控环境：全部自有benchmark进程（含RSS）只允许logical CPU `[0,2,4,6]`，process mask `0x55`；所有五角色一致，OMP_PROC_BIND=false且清除OMP_PLACES。准备与测量在同一允许mask内，但不逐OMP线程绑定、不锁频。记录原/实际process/system mask以及每次native调用前后caller CPU号（含80预热、400主要轮和80 A/A，共560条），CPU查询在wall区间外。端点必须属于预定mask；不因某CPU较慢择核，不丢慢样本。该控制只是新场设计，不从旧187/512迁移反推原因，也不与旧unbound绝对耗时直接比较或擦除旧反例。端点CPU不等于逐OMP worker迁移轨迹。

磁盘ROM、真实capacity、离线导出峰值、静态C99栈及五独立进程RSS分别列，RSS含Python/NumPy/库与流式SHA预检，不是核心总RAM。既有source ABI、图像语义和默认行为不变；不执行affinity/WASM或其它新机制。当前仅静态预案，未导出/编译/质量/计时。
