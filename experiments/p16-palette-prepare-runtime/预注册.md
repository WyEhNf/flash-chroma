# 95固定小palette字典准备（单版静态方案）

基于94，不改共享编译器、像素TU、模型、whole-cache资格、2^26预计生命周期像素阈值、8bit优先或精确回退。仅direct资格段由全cache copy/sort/unique及逐项lower_bound，改为固定512槽完整RGB24键线性探测。固定乘数0x9e3779b1取高9bit，无hash/容量/参数扫描；最多255占用槽，满负载仍小于1/2，完整键比较保证碰撞不合并。

第一遍含零空洞的完整cache发现唯一色，遇第256个不同色立即不发布direct并交原prepare_palette回退。成功后只排序≤255个整数色，回填槽的原升序ID，第二遍同一cache查询字典生成原u32 ids；原16MiB直接表和palette逐字节应与94相同。0xffffffff空哨兵不可能由RGB8 pack/零空洞生成；额外拒绝非RGB24键，不将哨兵当颜色。所有可能失败的heap分配仍在直接表发布前，之后只有noexcept编译和原诊断发布。

三个固定数组分别2048B键、512B排序ID、1020B有序palette，共3580B；另有计数、对齐和编译器栈帧，**不称零内存成本**。逻辑temporary_peak_bytes显式计入sizeof整个字典对象；构建启用-fstack-usage，保存相关.su及实际create/helper编译总帧，另读新进程RSS。它不代表跨调用栈精确峰值；std::sort递归等边界明确披露。相对旧whole-cache values拷贝减少的heap账单与固定栈增长分别列出。

固定有限原生合同13项：空输入、0与ffffff、255色升/逆序和第256色、同一初槽510的255/256完整碰撞键及跨511→0环绕、逆序碰撞、含零空洞的255/256边界、重复混排、非法哨兵拒绝。独立std::sort/unique及lower_bound提供精确颜色、排序和ID真值；最坏冲突合同另核255个连续占用槽，不能只用随机均匀键。

完整质量固定87/94/95，两实模型default/high下87scalar对94/95各7后端完整RGB8共56流；安全copy_direct/copy_palette对20个实/合成快照含空表逐字节；五hint有限/尾部/偏移、110拒绝，高低各8个u64独立oracle合同，真实N1/10/86/100照片32实际SHA。默认小N、超255与混合后缀原fallback必须相同，不能只测高hint成功路径；阈值不因新prepare收益调整。OOM/无AVX2未注入时如实列明。

正式性能尚未获窗口、未执行，须质量通过后另冻结/根代理grant。建议冷create与连续首组完整wall仍用N1/10/86/100三角色87/94/95、四独立worker、5正式+5AA按迭代交错；热控制固定N1/100 in/out1/4，warm2与64/9重复，保留全部原轮/实际末组SHA/源首尾SHA；12新RSS进程2模型×3角色×N1/100。94分母辨别新去重机制，87分母独立验证完整作业底线，不能用较慢前版代替原基线。热中间N未重测就不授全场热资格。每比较独立AA0.85..1.15，最劣worker100/90/80/70/60/50，失效原样留；无明显退化中位≤1.05且各worker≤1.10，不补跑、调门限、调hash或阈值。

进程允许集合0/2/4/6不等于逐OpenMP TID固定；逐TID helper方法另建独立控制协议，不能混入本单版或恢复94/92旧资格。本方案当前仅静态源/合同，未构建、未进行新数值或计时。
