# 原3B字典跨场变动：尚未执行的可证伪诊断

本计划只诊断冻结旧二进制的测量变动，不产生新优化、精度或速度档位，不恢复“稳健全情形50%”推荐。原八worker通过与4bank场有效39.8454%反例均保持；不会筛掉控制不佳的组后补跑，或选择最快结果。实施前还须冻结脚本和原二进制/数据SHA，并由root另行分配计算窗口。

## 固定对象与操作序列

只测原 `ref80` 和原3B AVX2 DLL；输入仍为同一235929600B百图、原地单线程，所有历史角色的模型先加载并保持存活，使同进程两序列的对象、ROM/源/目标地址和模型常驻集合一致。另记录每进程实际DLL路径/SHA、ROM地址/尺寸、src/dst地址和系统环境；地址只观察，不从事后相关性推断因果。

四个全新进程，每进程固定两个16组的四调用序列块：偶数worker先16组ABBA再16组BAAB，奇数worker相反。A=ref80，B=旧3B。每次输入恢复复制仍不计时；每个四调用组内不做整幅SHA或大文件IO，保持参考紧邻候选。每组末输出核完整百图SHA；不另加预热/验证调用，首组也保留，合计每进程128次、四进程512次。两角色已由前一完整域/百图验证且二进制身份固定；诊断不取代该正确性结论，全部操作序列和额外组末验证代价写入方法记录。

每个调用同时保存单调壁钟、`QueryThreadCycleTime`差、`GetThreadTimes`用户/内核差、组号和组内位置、调用前后`GetCurrentProcessorNumber`。每进程记录process/thread affinity且不主动绑定，实际caller始终单线程；端点CPU号相同不证明整个区间没有迁移。Windows文档说明周期计数与CPU计时器实现有关，不能换算成经过时间或直接当作主频，更不是retired指令计数器；`GetThreadTimes`记录线程用户/内核执行时间，但时间单位也不意味着该采样粒度。对应原始周期、CPU时间、壁钟和CPU执行时间/壁钟占比必须分列，不自行相除宣称某GHz频率，因粒度或计数边界出现大于1的比例也不截断。[QueryThreadCycleTime官方说明](https://learn.microsoft.com/en-us/windows/win32/api/realtimeapiset/nf-realtimeapiset-querythreadcycletime)、[GetThreadTimes官方说明](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-getthreadtimes)。

## 预先限定的假说与反驳条件

1. **单一共同乘性速率漂移足以解释变动。** 若相邻A/B壁钟均按相同比例变化，局部B/A比值比远隔参考稳定，则与此简化假说相容，但不能证明具体是调频或主机竞争。若A相对稳定而B的壁钟或周期比单独改变，就反驳“单一共同因子完全解释”；仍不能排除更复杂的频率、调度、内存和代码交互。
2. **组内先后顺序存在可复现影响。** 若ABBA与BAAB在同角色的位置效应有同向差异，可支持需要继续研究状态/顺序的判断。若两序列的角色比值相近，而各角色共同随时间漂移，则不支持单纯组内顺序解释。时间和顺序交互、地址相关性只描述，不冒充随机因果试验。
3. **壁钟差异主要来自线程未执行的间隔。** 若壁钟变慢而线程累计执行时间/周期并未相应增加，与此解释相容；若周期等指标也显著增加，则单纯“只被抢占”不足。线程计时粒度及计时器实现可能限制结论，允许“不足以辨别”。
4. **迁移或核心相关状态是候选因素。** 调用端点CPU号变化说明至少有端点迁移，可并列该标记与时间/周期，但不能据此认定时钟原因；端点相同也不排除中途迁移。所有核心/调用均保留，不选择最快核心，也不把此候选排除成H1/H2二选一。

操作性阈值在运行前固定：H1按每组两个A/两个B壁钟的中位形成局部B/A；若某worker的A时间`p90/p10<=1.10`，但局部B/A的`p90/p10>=1.25`，反驳该worker的单一共同乘性因子解释。H2若ABBA与BAAB局部B/A中位比至少3/4个worker同向偏离10%，记与顺序关联相容；若全部worker偏离小于5%，不支持本场10%量级的可重复效应；其余为不足。全部32组参与，`numpy.quantile(method='linear')`，不筛除异常或迁移组。这些是预先限定的经验诊断，不是假设检验显著性或因果证明，不改变50%性能底线。

不根据结果追加新进程、换次序、调阈值、改输入、绑核或改功耗。只公开全部组的时间序列、分布、相邻参考与周期/执行时间的并列表，报告是否支持/反驳上述**简化**假说或证据不足。即使诊断某些局部比值超过50%，也不会撤销原有效反例或把这些诊断数值作为新的正式优选。
