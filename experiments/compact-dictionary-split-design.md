# 17bit 块 ID 分平面：执行前设计

本阶段是独立的精确表示试验，固定 a399 四级模型与已经验证的 107707 个 16B 字典块。前一紧密 17bit 格式在合并八 worker 后只有四线程分离输出通过 50% 速度线；不能用第二场单独的四线程原地结果覆盖第一场失败。本阶段尚未运行，以下均为预先约定。

## 表示与读取依赖

新格式使用 `M16S`、版本 1；保留 32B 头部、1024B LE RGB32 palette 及固定 16B pool。块 ID 保持 17bit，但分成两个平面：

| 区段 | payload 偏移 | 字节数 |
| --- | ---: | ---: |
| 低 16bit，按块号连续 LE16 | 0 | 2097152 |
| 高 1bit，块号低三位选择位 | 2097152 | 131072 |
| 原字典 pool，顺序不变 | 2228224 | 1723312 |

对于 `block = RGB24 >> 4`，先分别读取 `lo = LE16(table + 2*block)` 和 `hi = table[2097152 + (block >> 3)]`，然后计算 `id = lo | (((hi >> (block & 7)) & 1) << 16)`。最终 ID 是 `table[2228224 + (id << 4) + (RGB24 & 15)]`，之后读 palette。两个平面读取互相独立，但 pool 和 palette 读取仍有串行依赖；多一次 map 读取可能抵消减少乘法/移位的收益，不预先断言变快。

紧密 17bit 原实现计算 `bit=17*block` 后读跨字节 packed word、变长移位并 mask。3B 偏移实现直接读绝对 pool 偏移。新实现只改变 map 布局和 lookup，沿用已经冻结的桌面 AVX2 像素循环，不叠加 ISA、存储算法或有损量化修改。

## 范围与借用契约

`block` 范围为 0..1048575；低平面最后读取字节 2097150..2097151，高平面最后读取字节 2228223，均严格在 map 内。C99 按字节 LE16 读取；桌面使用 `memcpy` 读取两字节再读一字节，不依赖 ROM 对齐、裸指针类型转换或额外 padding。新 map 不再使用原紧密格式的四字节跨 map/pool 读取。

prepare 必须扫描所有块 ID 并验证 `id < 107707`，以及所有 pool palette 索引。完整 ROM 借用保持不可变；失败清零、out/ROM 重叠时保持输入、零长度、部分输入输出重叠和地址范围检查继承原契约。桌面路径的最后一个 pool 字节必须紧贴 `PAGE_NOACCESS` 单独验证。额外构造最后一个 map 块引用最后一个 pool 块，覆盖最后低平面/高平面地址和 pool 尾部，不只依靠照片实际命中。

实际 ROM 为 `32+1024+2228224+1723312 = 3952592B`，Windows x64 model 为 1056B，借用常驻容量为 3953648B，与紧密 17bit 相同。离线重排的 Python/NumPy 峰值和 prepare 后新进程 RSS 分开报告。磁盘 ROM、实际容量、prepare/运行 scratch 与 RSS 均不混写。

## 冻结的验证与性能计划

先冻结生成器、C99/AVX2/适配器源码、export/build/verify/bench 脚本、旧 DLL/ROM SHA 及完整模型输入。离线解码必须重建全部 `256^3` 个 ID，与 `a020c67a0e8ce77e668e6c6d85206af53005923316b4778194637182b4cfaea0` 一致。C99、桌面 scalar、AVX2 单/四线程分别完整域 SHA 验证；有限长度/非对齐/原地/分离哨兵、坏高位索引、格式拒绝、保护页和强制尾部测试全部通过后才计时。

正式性能固定七角色：同场 78、80、原 32bit 字典、已测 3B 字典、已测紧密 17bit 字典、新 AVX2 分平面、新 C99 分平面；旧三角色加载原二进制而不重编译。四个新 worker 采用轮转/反序，每接口和线程数分别一次完整百图预热及五次完整百图计时；计时范围不包含输入复制，使用相同原地/分离接口、单/四线程及独立角色 RSS。四线程 C99 通过同一 OpenMP 桌面适配器，不宣称纯 C99 自动并行或独立 C99 DLL 的吞吐。

每 worker 的分母使用同场 78/80 较快耗时；四 worker 最劣值决定 100/90/80/70/60/50 速度档，精度逐字节不变才记 100%。A/A 单对须在 0.8..1.25，四 worker 中位须在 `1/1.1..1.1`；失败的情形保留原值并清空正式资格。另列新旧同容量格式配对代价，不把历史跨场漂移解释为布局收益，不拼接不同场次最好值。

本阶段不改变官方 SLUT、33³ 节点、第一阶段分输出坐标或模型训练。M16S 是派生运行时研究格式，赛事许可尚无结论。本文件只记录执行前方案，不作为已经运行、通过或加速的证据。
