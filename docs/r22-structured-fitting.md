# R22：结构证明、整数曲线拟合与默认拟合器的CSR优化

日期：2026-10-15。串行执行，未推送。官方测试集和Threshold尚未取得，以下采用本地生成数据，不能判定官方精度通过。

## 先证明结构，再降低离线问题维度

新增显式候选`ls_tetra_structured` / `dp_structured`。对完整RGB8 LUT的每个输出通道，检查它是否只依赖某一个输入轴，允许轴交换和常量通道。检查覆盖全部256³输入颜色的每个字节；任何一个例外都拒绝结构化路线，转用R21的一般三维边界LS。不是依据少量探针猜测曲线类型。

若证明成立，在原有DP网格及序列化Q16轴表上拟合三个整数曲线。对于固定输入轴，四面体重心权重对该轴两端的合计恰为`1-f`和`f`，所以扩展的三维节点表执行结果严格等于一维Q16插值，包括半单位向上舍入。曲线最终展开成普通`m³×3`个uint8节点；运行时仍查四张三维表，没有附加曲线表、全色查表或浮点中间输出。

每个轴的全部256个输入值恰好分配到一个网格区间。对区间两端所有256²种整数节点组合，计算该区间最大绝对字节误差和平方误差和。先用瓶颈DP求全局最小最大误差`E*`，再限定每条区间边误差≤`E*`，用第二次加法DP求最小SSE。不能直接在每个状态只保留一个`(max,SSE)`字典序最优解，因为后续较大的max可能掩盖之前的max差异，改变SSE最优路径。

回溯后重新计算完整256值的两个目标，与DP证书核对。证书范围是**单通道、固定轴网格、整数节点域**；不声称DP轴节点自身全局最优，也不保证RGB欧氏误差或四级最终误差最小。一般三维回退模型必须与R21同输入、同尺寸模型逐字节一致。新候选保持显式选用，不加入默认候选集。

## 默认jitter拟合器：减少组装而保持模型兼容

将`ls_tetra_jitter`从每样本展开16个节点对的COO组装改为每行最多四项的CSR设计矩阵，缓存`H=AᵀA`与`Aᵀ`，复用后者计算三个通道的目标项。采样、DP轴、CG参数、先验和整数精化规则保持原值。

首次兼容性检查发现`clip-7/m33`第二级有10个节点字节改变。保留失败后，直接核对发现两种组装的H、b数值完全相同，但新H列索引未排序。欠约束系统的CG浮点归约顺序变化使解最大相差约0.1214，最终跨越整数精化边界。恢复旧COO的有序列索引后，浮点解及节点恢复一致。排序仅用于替换旧jitter组装；不改变R21已经冻结的加权边界组装顺序。

阶段门禁要求七组历史模型的全部28张表与冻结版本逐字节一致。性能比较使用冻结R21源码启动独立进程，7对AB/BA交替执行完整四表DP+jitter/m33拟合；输入加载、导入、序列化和模型缓存查找不计入拟合计时，每次仍包含首次矩阵构建。矩阵组装加速比与完整拟合加速比分开报告。

## 缓存跨进程一致性修复

第二次验收中，子进程成功原子发布模型，但父进程不能命中。保留的manifest证明唯一身份差异是`platform.machine()`在子进程返回空字符串，父进程返回`AMD64`；模型自身来源、参数和校验均有效。缓存现改为记录稳定的`sysconfig.get_platform()`和解释器指针位数，不再依赖Windows WMI架构探测。架构信息仍绑定身份，字段改变使旧版本安全地缓存失效，不修改历史证据。

现有集成检查增加空/非空WMI结果不影响身份、解释器平台改变必须改变身份的回归检查。曲线测试用缩小节点域上的独立穷举对照DP全局最优，并检查通道置换、常量通道、完整表中单个内部例外的拒绝行为。
