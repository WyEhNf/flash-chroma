# R28–R51 阶段研究进展

当前停止状态以[版本化检查点](../datasets/problem16-v1/matrix-checkpoint.json)为准：已尝试4,471/7,917项，4,465条有效观测、6项拟合阶段失败，留出尚未执行。R51最后一条观测已归并，总账本4,602条。

下列条目保留各阶段的范围与当时状态。“仍在运行”“待导入”等历史描述不替代上述检查点；主开发环境和构建命令以根README与TOOLCHAIN为准。完整实验数据和原始执行目录没有随Git提交，台账复核需要对应data/artifacts或已归档证据。

**R28数据与case账本：** 200条完整四级LUT链、320张分类合成图、23组探针已完成完整审计；常量链与重复最终变换单独标记。`corpus`、`casebook`子命令维护数据、失败、mean/max最优与容量Pareto。9策略×3尺寸×200case的5400候选矩阵已开始；首个case的27项结果不能代表类别sweet zone。[范围与状态](r28-corpus-program.md) · [数据目录](../datasets/problem16-v1/README.md)。远端补充的五张Kodak自然照片保留独立来源与引用队列。

**R30/R31端侧运行时：** 新增独立无堆分配、无I/O和无浮点的[C99库](../portable/README.md)，支持行步长、分块、原地处理和经证明的常量/曲线/节点捷径。3组完整RGB立方体与冻结原生结果一致；AArch64大小端模拟执行的12个完整输出流也一致。实体手机性能、功耗及新库配对速度尚未测量。[集中验收及边界](r30-portable-runtime.md)。现有C++默认AVX2路径保持原实现。

**R32格式门禁：** CPU补齐网格元数据检查，CPU/CUDA在竞赛入口检查PNG原始RGB8类型。集中拒绝全部30/27个适用负样本；有效模型完整色域及每后端100合成图+5自然照片保持一致。[修复与复用证明](r32-format-contract.md)。

**R33/R34新算法与阶段比较：** 一箱一节点的单调选择让17/33箱控制在合法m内零误差；两级前瞻仍以各自原表为节点标签，stress-13/m33的全色域max由38.4187降至2.2361，mean降至0.30875。实际100图最差mean1.0，五张照片在CPU/CUDA/C99上逐字节一致。7对同资源比较确认AVX2相对标量加速2.0709倍，未证明新模型映射提速。[算法及拒绝的候选](r33-monotone-bins.md) · [严格阶段结果](r34-candidate-results.md)。这些结果只覆盖预声明先导case；原5400矩阵与新策略的类别留出研究仍未完成。PDF仍为R27冻结报告。

**R35结构化运行时接入：** 新增显式`tetra_c99`、`tetra_structured_avx2`及统一`plan`诊断。完整节点/前缀证明用于常量、曲线、单节点和通用路径。两个构建的完整独立参考门禁、9个真实完整色域输出流和每新内核100+5图像均通过；尚无新内核配对速度结论。桌面桥接副本与缓存计入运行内存。[部署与验收](r35-structured-runtime.md)。R36的2517项扩展计划已预声明，两套训练阶段完成并冻结联合规则前均不执行留出。

**R39/R40结构化性能与case选择：** 3模型×3后端的9项比较共162次计时已完成，统一16线程、固定100图，双侧符号检验对九项作Holm校正。结构AVX2相对普通AVX2在新压力与17箱模型上分别加速1.96477/3.17268倍，通用clip模型未证明显著改善。九项配置已绑定正确性证据登记到case账本，区分观测最快、证实最快和耗时/模型内存Pareto。[全部结果、内存代价及边界](r39-structured-performance.md)。默认auto仍保持原有选择，矩阵留出研究和实体手机性能尚未完成。

**R41矩阵恢复：** 修复Windows控制器路径键导致的启动错误，基线和扩展均已有实际运行的开发/校准/回归进程。联合规则工具可检查完整4,680项训练覆盖；正式冻结与留出评估仍待完整训练完成。[恢复证据位置、规则口径及操作命令](r41-matrix-resume.md)。

**R42类别训练对照：** 固定快照包含2083项训练记录，42/180组已完成双seed全13策略对照。mean与max经常选择不同策略，多个指标存在并列最优，并观察到m增大后最终误差反而增大的case；覆盖不足组不排名。[实际比较与边界](r42-training-comparison.md)。这不是留出sweet zone结论。

**R43 ROM部署：** 新增`python -m lutlab.portable_export`，生成保留原四表字节与来源的C99只读数组，固件无需模型文件系统或Python。m17/m33两套编译数组及完整色域结果均匹配冻结原生输出，四种freestanding目标对象编译通过，三线性模型明确拒绝。[部署接口、资源开销与验收](r43-rom-export.md)。本轮没有实体手机性能测量。

**矩阵里程碑：** R36开发720、校准720、回归357项均已完成，控制器正常退出；扩展留出720项尚未启动。R29基线仍在运行，两矩阵训练齐备并冻结联合规则前不查看留出输出。

**R44/R45适用区域与图像边界：** 四个新策略的180组训练对照全部齐备，组合策略相对adaptive_bins在9组改变指标，其余171组四指标相同；恒定最终链单独标记。[类别差异与容量反例](r44-new-policy-regions.md)。三个代表源已完成6条完整色域流、600次标准图与五照片多后端核对；其中一个源的100图最差mean仍为14.0382，保留本地精度失败。[实际图像结果及待导入状态](r45-representative-images.md)。这些结果不替代全13策略与留出评估。
