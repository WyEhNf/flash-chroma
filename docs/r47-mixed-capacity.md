# R47：四级混合容量的精确搜索与可部署模型

在 gamma、logistic、filmic 三个家族的 18 个训练源上，分别选择每级 m∈{17,25,33}，枚举每源 81 个组合，共 1,458 个训练配置。相对这些源已经完成的全 13 策略×3 尺寸共39个候选，9个源降低最优mean，其中5个源同时减少节点负载。该结果只覆盖这三个已证明适用的家族，不是整个数据集的通用最优结论。

预声明计划为 `datasets/problem16-v1/mixed-capacity-plan-r47.json`。原 7,917 项矩阵保持不变；本研究另声明27个源的2187个逻辑配置，其中81个均匀配置与既有父模型重合，2106个为新增混合配置。当前只完成18个训练源；9个留出源的729个配置尚未评价。

再次核对原题截图，每一步的m范围明确为17..33，但四张表是否必须共用一个m没有明确的官方接口说明。本研究采用每级可独立选择m的解释；本地格式和运行时兼容已验证，不能据此宣告官方提交接口兼容。统一m的原矩阵继续独立保留。

## 计算的完整性

每个目标先逐颜色检查整个256³真值，证明输出通道c只依赖输入通道c；每张父模型再检查全部m³节点，证明同样的对角结构。轴置换、多个输出共享一个非本通道输入等情况不能使用这项独立性推导。

在这些条件下，四级Q16算子可以精确写成三条完整256值整数曲线。每级仍按其序列化轴表插值并输出uint8，再进入下一级。三个输入轴在完整RGB色域上独立枚举，因而三条逐通道平方误差直方图的整数卷积恰好覆盖全部16,777,216种输入。直方图计数与中间总和均不超过2²⁴，不存在int64溢出；mean、RMS、p99和max由完整直方图计算，而非采样估计。

全部54个均匀尺寸配置的六个标量统计均与R36既有原生完整色域结果相同。1,458项是完整解析计算的配置数，不能写成1,458次新的原生色域执行。目标／节点证明失败的源不能用抽样结果替代。

## 已观察到的精度与资源收益

mean为完整色域RGB欧氏距离均值。以下参照均为该源全13策略×3尺寸候选中最小mean的配置；资源列比较这两个mean最优配置的RGB节点负载。节点负载不含轴表、模型头、代码或RAM准备对象。

## 一次集中原生验收

完成的原生验证共45条完整色域输出流：42个CPU选择配置、2个混合尺寸CUDA配置，以及1个实际编译的C99 ROM配置。每条CPU输出先逐颜色证明与预测的整数曲线一致，再核对完整误差统计；CUDA和C99输出按完整SHA256与已验证CPU结果一致。

mean目标按mean、节点字节、尺寸字典序选择。max存在两个有意义的并列偏好：现有case账本按max、p99再考虑存储；容量指南按max、节点字节和尺寸字典序。首次验证覆盖34个配置，随后只补充8个容量优先的不同选择，复用10个已验证选择，没有重跑已经通过的配置。两种选择都保留，未把较低p99与较低存储混称为同一优势。

本轮未测速，也未新增混合模型的100图资格；不能由并行验证耗时推断性能。R35/R39既有内核速度结论仍只适用于其原测模型与资源组。

## 来源合同与ROM交付

新增`lutlab.stage_bundle`组装模块，只把每级对应位置的已验证父模型按字节复制。四个父链必须拥有相同的四个有序原始LUT身份，并明确为独立四面体映射；每级保留自己的m及其原始SLUT v1字节。没有生成复合表、残差标签或新的拟合结果。

新的来源包装清单为`independent_stage_bundle_v1`，保存各父清单副本和哈希。原均匀缓存格式保持不变，公共合同入口增加专用验证分支；父级顺序错误即使重新计算包装清单自身哈希仍被拒绝。模型自身仍是已有SLUT v1格式。公共`lutlab plan`已实际接受混合尺寸模型。

Python集成示意：

```python
from pathlib import Path
from lutlab.stage_bundle import assemble

bundle = assemble([
    Path("m17-parent/stage1.slut"),
    Path("m33-parent/stage2.slut"),
    Path("m17-parent/stage3.slut"),
    Path("m17-parent/stage4.slut"),
], Path("mixed-model"))
```

`portable_export`同时保留这类包装的四份父清单，生成的C99仍只借用四个只读数组。实际ROM例为m=[17,33,17,17]，序列化模型数组负载168,460 B；64位主机准备工作区仍为12,560 B，四级走各自曲线路径。这不是实体移动设备峰值RAM或性能测量。

## 已冻结的指南与剩余工作

`datasets/problem16-v1/mixed-capacity-rules-r47.json`已经在任何R29、R36或混合研究的留出输出之前冻结。三个家族×三档强度×15档节点负载预算，共135条规则，分别保存mean和worst-max选择。每条只使用两个训练seed；p99报告为两个源的较差值，不作为容量规则的并列判据。

这些是描述性指南，尚未证明未知seed上的sweet zone。原13策略联合规则仍需等基线完整训练后另行冻结；混合研究的729个留出配置也需之后评价。42条原生模型记录已在后续R50迁移的无写入器间隙正式导入总账本，没有并发发布。
