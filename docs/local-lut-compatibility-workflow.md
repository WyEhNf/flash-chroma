# 本地LUT与照片适配度工作流

本轮按用户要求只保留本地代码和结果，不创建PR、不推送、不上传实验产物。结果位于被Git忽略的 `artifacts/local-lut-study/20261016/`，入口报告为该目录下的 `REPORT.md`。

## 与现有CI的关系

参考 `.github/workflows/correctness.yml` 的“先正确性、后其他工作”、固定OpenMP线程及单线程BLAS约定。现有CI仍只负责原项目C++/Python正确性，本轮没有改动其权限、触发器或自动上传步骤，也没有把耗时研究塞进普通PR门禁。

本机是Windows/Python 3.12，现有g++启动时报DLL错误，未找到CMake。因此本轮使用Numba/LLVM CPU后端，完成可独立核对的源文件读取、像素内核和四级融合测试；没有声称完成原有C++/CUDA门禁，也不能将本轮时间与历史C++/CUDA时间混排。

可选测试在缺少Numba/tifffile/psutil时显式skip，避免给默认CI引入未锁定研究依赖。实际研究必须在依赖完整的环境运行；跳过测试不等于研究验证完成。本机包版本保存在 `experiments/local-study-requirements.txt` 和结果 `run.json`；它是独立环境，不是现有Pixi锁定环境的执行成绩。

## 一条命令复现

从仓库根目录，在依赖完整的Python 3.12环境执行：

```powershell
python scripts/local_compatibility_pipeline.py --output artifacts/local-lut-study/20261016
```

步骤依次为：

1. 源格式轴序、通道旋转、Q16已有实现对照、三线性、六节点棱柱、端点、精确分位数、四级整数融合测试。
2. 三个本地进程各处理不同LUT，执行抽样筛选，不进行正式整图性能排名。
3. 核对参考表和模型哈希；全部筛选结束后，单进程串行调度完整100图质量和吞吐测试。映射内核固定四线程。
4. 三组四级数值链分别测试10种配置、17³/33³，保留每级RGB8整数边界。
5. 入围单级模型穷举256³颜色，输出 `cube-finalists.json`。
6. 重算全部配置的抽样逐图指标，逐项核对与初筛汇总一致，再汇总中文报告、CSV和图表。
7. 对素材、参考表、模型、代码身份及各阶段记录数量执行最终核验，输出 `audit.json`。

检查点按LUT原文件SHA划分目录。已完成的筛选或完整复核可复用；源文件、照片、核心算法、配置或参考解释变化时，程序拒绝混用身份不同的结果，应改用新输出目录。正式测速前再次核对参考表和SLUT字节哈希。手工修改检查点不受支持。

Windows短暂文件占用时，`scripts/study_worker.py`只为JSON检查点替换注入有限重试，不改变数值算法、拟合或指标定义。本轮两次筛选进程因此中断，已有检查点保留，通过同参数恢复完成；原失败日志位于本地tmp目录。算法失败则保留异常、诊断和状态，不能计为精度通过。

若单独调用模块进行开发，需设置 `PYTHONPATH=python`、`OPENBLAS_NUM_THREADS=1`、`MKL_NUM_THREADS=1`、`OMP_NUM_THREADS=4`、`NUMBA_NUM_THREADS=4`；推荐使用上述统一入口以确保质量测试、缓存核验和测速互斥。

## 配置与计量范围

20个基础配置包括：直接采样配三线性/四面体/最近邻/零阶保持/棱柱；精确坐标重采样配两种线性恢复；Box配两种恢复；三线性LS配三线性及显式算子失配对照；四面体LS、整数精化、jitter；曲率网格、误差网格、DP网格；边界/全节点支撑及尾部加权。五个来源各选一张额外执行IRLS和guarded。组合数量不是全部独立算法数量。

所有稀疏节点均为RGB8，m取17/33。筛选使用每图4096个固定随机像素；入围规则为每LUT最低mean、最低max及33³直接采样四面体基线，去重后再测完整100图。选择集和完整复核集来自同一批照片，因此不是独立盲测。未入围配置没有完整100图性能数字，不用抽样时间伪造整图结果。

原始LUT按各格式轴序读取：CUBE与Hald为R最快，3DL为B最快；3DL按OCIO口径推断输出位深并处理本批近恒等输入轴。源网格三线性恢复后clip/round为256³ RGB8黄金表，单级稀疏化拟合这张表。完整源政策记录在各LUT结果中。特别是Lobster负值/大于1输出的裁剪发生在显式烘焙步骤，原素材保持不变。

本工作流衡量数值还原能力，不评价创意风格的审美质量，也不推断未声明的摄影色彩域。外部LUT原本已稀疏，源三线性恢复会给相同插值结构的候选一定先验优势。四级链只作为明确声明的数值级联，不保证四份创意LUT的真实摄影色彩域兼容。

精度遵循题目RGB欧氏距离。逐图报告mean/RMS/p99/max和阈值像素比例；全色域指标另列。映射时间不含PNG解码、JIT编译、拟合、参考表生成和误差统计，包含输出分配；完整100图重复3次并保留原始计时。源加载、拟合、串行映射、四级链与宿主RSS分别记录。

R25/R26原生全域拟合库、C++/CUDA部署性能、神经网络、高阶样条及棱锥插值不在本轮实际执行集合，已在报告中列为待补。当前结果不能据此宣称穷尽所有路线或获得官方分数。
