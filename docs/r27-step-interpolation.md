# R27 阶梯插值与可达颜色布点

日期：2026-10-15。串行执行，未提交或推送。用户已确认官方数据和 Threshold 尚未取得，本轮只能报告本地数据结果。

## 算法与题面约束

题面允许联合设计稀疏化和插值算法。本轮新增显式候选 `adaptive_full`，按以下顺序选择每一级模型；没有加入默认候选。

1. 对完整 LUT 的三个输入轴，逐个比较相邻切片。每次比较覆盖另外两轴的全部颜色及三个输出通道。如果每轴全部变化位置加上 0、255 后不超过 m 个节点，则构造精确零阶保持表。
2. 如果前缀输出已有一个完整、有限的超集，并且超集中每个分量的取值加上 0、255 不超过 m，则将这些取值纳入对应网格轴。所有节点取自该级自己的原始 LUT，因此在这些输入上精确。
3. 不能证明时，使用 R25 的 DP 网格与全色域拟合；必须保持完整模型字节不变。

补足网格时，总是拆分当前最大整数间隔，直到每轴恰好 m 个严格递增节点。每级存储仍是 `m³×RGB8` 节点，四级各自映射，每级输出立即成为 RGB8。没有使用复合真值作为单级训练标签，也没有残差补偿。

零阶保持使用既有 SLUT v1 的权威轴表表达：晶体索引仍按真实输入位置确定，Q16 权重坐标在输入小于 255 时取 0，输入为 255 时取 65536。这里**改变了插值政策**，不是声称这些权重仍是网格几何距离比例。它在所在晶体中选取下端点（末端输入选取末端点），全部颜色信息仍只在 m³ 节点中；轴表仅表达位置与选择规则。CPU/CUDA 的整数算术与文件格式没有修改。

## 正确性依据

完整切片相等证明：在任一划分区间内改变一个坐标，其余任意坐标不变时，原始 LUT 的输出不变。依次把三个坐标替换成所在区间下端点，输出仍保持不变。因此三维耦合的分段常量 LUT 也能被精确表示，不要求三个输出通道各自只依赖一个输入轴。补入区间内部节点不改变该性质。

所有 Q16 坐标均为 0 或 65536 时，四面体权重恰有一个为 65536，其余为 0。因此任意输入输出必属于存储节点集合。这个集合最多 m³ 项，可以作为全色域前缀输出的超集；后续将该集合逐点通过实际稀疏算子，仍得到完整输出超集。布点级对整个传入超集与自己的原 LUT 直接查表逐项核对。超集只用于离线选择网格，不是运行时新增查色表。

条件精确仅针对**实际稀疏前缀输入**上的该级映射；不意味着该级在全部 256³ 输入上精确，也不意味着修复前级已经引入的误差。不满足节点预算、没有前缀集合证明的情况均回退。

## 阶段验证口径

本轮固定 R25 的 13 组模型配置。全部重新拟合；每个回退级必须与冻结 R25 表逐字节一致。如果四张模型都不变，核对原始 LUT、参考复合表、100 张图片、清单及两个执行文件的哈希后，复用 R25 的真实执行证据，并在记录中标明复用。如果模型变化，则重新执行 CPU/CUDA 全部 256³ 输入和 100 张 1024×768 RGB8 图片验收。

另用固定种子 2026101527 构造前三个三维耦合分段常量完整 LUT，以及一个非分段常量的耦合第四级。前三张使用 m=17、18、25，第四张使用 m=33 的可达颜色布点。以四张完整表独立串联的输出为真值，对两个原生后端各检查全部 16,777,216 个输入颜色，同时验证文件保存/载入保留权重。另检查连续变化表、缺失前缀证明、超预算和非法颜色集合必须拒绝精确声明。

R25 原生全色域法方程没有修改；在源文件、包装器、测试、动态库及独立 COO 参考函数一致的前提下复用其完整 oracle。其余 Python 合同检查本轮集中运行一次。

## 完成结果

15项Python合同检查通过（13.65秒）。新三维耦合控制在两个原生后端各穷举全部256³输入，与独立完整四表串联逐字节一致。13组CLI拟合完成；12组的全部48张表与R25相同，复用原验收。压力组仅第二、三级变化，重新通过CPU/CUDA全色域与实际100图一致性验收。整个主阶段114.43秒。

## 当前模型的配对性能与开源基线

7对AB/BA，每进程3次；两个声明配置均先核对实际100图的235,929,600字节输出。

- CPU gather/16线程/batch：86.864 ms/100图；CUDA batch100普通主机往返：67.7566 ms/100图。配对加速比中位数1.296051，95%重采样区间1.215461-1.364455，7/7更快。该比较没有声称这两个配置在新模型上全局最快。
- 同模型4工作线程下，CPU AVX2逐图271.589 ms/100图，OpenColorIO 2.6 Python buffer接入1572.6404 ms/100图。配对加速比中位数5.739313，区间5.408793-5.879028，7/7更快；不能外推OCIO全部C++/GPU部署。
- OCIO的float32映射与Q16在16,911个输入上不同。其全色mean为0.3751018563、RMS为1.1023269868、p99与max相同，100图最差mean为0.7824085105且全部通过示例门槛。其平均误差略优，速度比较不是完全相同输出定义的竞速。

当前CPU16准备后模型1,048,396字节，GPU模型599,568字节。CUDA显式图像缓冲峰值450 MiB；CPU16/CUDA宿主进程峰值工作集中位分别480,153,600/1,077,280,768字节。后者不是GPU峰值显存。

入口：`python -m lutlab fit --inputs <四张源表> --m 33 --grid dp --method adaptive_full`；候选`select --profiles adaptive_full`。仍为显式候选，默认候选不变。阶段脚本为`scripts/r27_step_study.py`与`scripts/r27_industry_study.py`。
