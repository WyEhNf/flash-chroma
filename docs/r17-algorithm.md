# R17：保留独立四级语义的整数拟合改进

本轮保留 `ls_tetra_int`，新增可选 `ls_tetra_q16`。每张稀疏表仍独立拟合其对应的完整 LUT，运行时仍依次执行四次 Q16 插值和整数舍入。没有把前级误差吸收到最后一级，也没有复合成单张稀疏表。

## 1. 原有整数精化的等价加速

旧 `int_refine` 优化的是未作最终输出舍入的二次目标

`f(x) = 0.5 xᵀ H x − bᵀ x`。

节点按三个坐标的奇偶性分成八组。同一个晶格立方体的八个角点具有不同的奇偶组合；一个四面体使用其中四个角点，因此同组不同节点不会共同影响任何一个样本。由此，来自四面体插值法方程的 `H` 在同组节点之间没有非零非对角元素。

某个节点的 `+1` 和 `−1` 目标变化分别为 `g + Hjj/2` 与 `−g + Hjj/2`。若 `+1` 被接受，该节点的梯度增加 `Hjj`，逆向 `−1` 不可能紧接着改善目标。同组其他节点也不会改变它的梯度。因此可以从一次 `H @ x − b` 同时决定两种方向，将每组的稀疏矩阵乘法从三次减到一次；仍逐组推进，仍独立处理 RGB 三通道的二次目标。

这个结论依赖非负样本权重、四面体局部支撑、同组节点互不耦合。它不是适用于任意稠密或带跨单元正则项的 Hessian 的通用更新规则。原算法自身也依赖这个分组前提。

阶段比较保留了旧实现，针对三个场景、两个尺寸、共 24 个单级模型逐节点比较，结果全部一致。单次局部计时为旧实现约 14–29 ms、新实现约 5.7–10.7 ms；它只反映该精化步骤，不能称为整个拟合流程或图像处理速度提高同样倍数。

## 2. 真正按 Q16 输出接受的可选精化

旧二次目标与最终 RGB 色差之间隔着整数节点量化、Q16 输出舍入以及后续三次映射。新方法以旧整数解为 incumbent，针对节点的 `±1` 候选直接计算运行时同样的整数累加及半上舍入，接受标准为实际 RGB 欧氏距离之和严格下降。

在固定奇偶组内，一个样本最多有一个非零权重节点。各节点改变的样本集合互不相交，所以可以用 `bincount` 汇总各节点的真实 ΔE 变化并批量更新。相等分数可能改变零权重顶点的选择，但零权重已移除，不破坏独立性。RGB 欧氏距离耦合三个通道，因此新方法必须依次更新输出通道，不能用三个互不相关的最小二乘目标代替它。

所有节点仍在 `[0,255]`。Q16 权重非负、和为 65536，因此累加器不超过 `255 × 65536 = 16,711,680`；加半单位后仍在有符号 32 位范围内。三通道误差平方和最多为 `3 × 255² = 195,075`，可预先缓存平方根表，避免为每个候选反复求平方根。

最多进行三轮。单节点提案先禁止训练样本最大误差超过当轮起始值；整轮完成后还需满足：

- 训练样本的 mean ΔE 严格降低；训练 mean/RMS/p99/max 都不能退化。
- 独立守护样本的 mean/RMS/p99/max 都不能退化。
- 任何一项不满足，回滚整轮并停止，保留上一个已接受模型。

守护条件不直接声称最终四级图像或全色误差也不退化。各级输出分布发生变化后，后级的非线性与量化可以放大或抵消差异；正式候选仍必须经过实际四级运行路径的独立验收。

## 3. 样本、诊断和失败处理

训练使用固定 `64³` 均匀子网格；守护使用固定种子的 65,536 个随机颜色，并排除训练颜色。守护集参与算法的接受与回滚，不能再作为未参与选择的盲测集。

阶段实验另冻结 262,144 个随机评估颜色，排除训练和守护颜色。216 个边界组合另行报告。此批数据是合成 LUT，三个场景为 `isp-0`、`clip-7`、`warp-7`；尺寸只比较 17 与 18，没有进行全参数扫描。未公开的官方数据、阈值和判定粒度仍未知。

CG 现在记录每通道状态、迭代数、相对残差和有限性。输入非有限、迭代未收敛、结果非有限或残差异常时，抛出带 `diagnostics` 的 `FitConvergenceError`。调用方的原子缓存发布只有在全部拟合成功后才能替换缓存；不能将失败的部分 RGB 解发布为新模型。成功的逐级报告通过 `stage_info` 保存在模型来源记录中。

最小回归检查位于 `tests/test_fit_contract.py`：真实耦合 SPD 系统的一轮 CG 失败与非有限输入拒绝；一个实际 Q16 目标下降和守护退化整轮回滚控制。这些检查用于防止契约退化，不代替阶段验收。

## 4. 本批有限结果

环境为 Windows 11、Python 3.13.12、NumPy 2.4.6、SciPy 1.17.1，拟合过程将 BLAS 限制为单线程。一次完整脚本耗时 42.54 秒，包含合成完整 LUT、拟合、序列化、哈希和抽样评估；不是官方计时口径。

24 个单级拟合中，23 个保留原解。仅 `clip-7 / m17` 的第二级接受一轮：四级抽样 mean 降低约 1.76%，p99 降低约 7.42%，max 未变。这证明新接受规则可以带来实际四级改善，也表明不能据此把新方法无条件设为默认。多次训练 mean 改善同时伴随守护尾部上升的提案已经回滚，负结果保存在原始 JSON。

本批三个场景的 `m18` 平均误差均低于 `m17`，但不构成 m18 普遍最优或全部场景有效的证明。尺寸选择和拟合方法选择仍应以官方合同与实际候选的精度、成本、内存共同决定。
