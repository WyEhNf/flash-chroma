# R34：新候选的实际图像与严格性能比较

R33 的 `lookahead_bins/m33` 已在一次集中阶段中通过有效模型合同、CPU/CUDA 完整 RGB8 域一致性和实际 100 图路径检验。它改善了已用于调参的 stress-13，不能据此确定未见源类别的最佳策略或官方得分。题面误差为 RGB8 欧氏距离，官方 Threshold 和数据仍未取得。

## 精度与端侧一致性

CPU/CUDA 使用 R32 修复格式门禁后的独立执行文件；本轮完整 256³ 统计复现 R33：mean **0.3087506316**、RMS **0.5731612868**、p99 **1.4142135624**、max **2.2360679775**。相对 R27 的 max 38.4187454，明显减少了大误差尾部，仍没有全域 max<2 保证。

固定的 corpus-v1 100 图由原生图像入口实际执行，逐字节匹配各自完整色域映射，两个后端输出也逐字节相同。100 图最差单图 mean 为 **1.0**，全部满足本地示例的严格 mean<2。这个队列包含已知合成类别，不能当作未见源留出测试。账本已为该图集哈希增加一条实际执行资格观测。

## 预声明的 7 对比较

使用相同的 100 张内容唯一、1024×768 RGB8 图像。R29 拟合进程均已停止后才计时。每一对固定执行文件、CPU 线程数、批处理、输入和运行参数；AB/BA 顺序交替，每轮随机排列比较顺序。保留全部 42 次运行，不丢弃不利样本。

时间包含普通宿主 RGB 输入复制、四级映射及普通宿主输出；CUDA 包含普通内存与锁页内存之间的复制、H2D、D2H。拟合、模型加载、解码、内存分配、输出编码和校验均不计入。未绑定 CPU 核，仍由系统调度。

前两项区间都跨越 1，未证明新算法使映射更快。第三项确认该固定配置下 SIMD 有显著实际收益（单侧符号检验 p=0.0078125）。配对比值中位数与两个时间中位数相除并不一定相同；相同候选出现在不同比较里，计时也分别保留，不能挑一个最快数代表全阶段。

本轮使用新的 corpus-v1 队列，不能与 R27 的旧 100 图队列直接比较绝对毫秒数，也不能把不同 CPU/CUDA 比较行的时间强行拼成一次配对结果。上述统计不保证其他图像、机器、温度或操作系统负载下的速度。

## SIMD、汇编与部署状态

默认原生内核为 `tetra_avx2`：C++ intrinsics 显式生成 AVX2 指令，一组处理 8 个像素并融合四级计算。`tetra_avx2_scalar_gather` 仍使用向量算术，区别是节点收集方式；本轮严格比较使用这一曾测较好的变体。源码中的 `tetra_asm` 没有像素汇编实现，明确报不可用；`xgetbv` 的少量内联汇编仅用于能力检测。

已有 AVX2 指令加速不等于手写汇编已经优化完毕。改写汇编、ARM NEON、实体手机运行和功耗均无新证据。便携 C99 的结构捷径已经正确性验证，尚未接入 C++ 默认向量内核或取得配对速度成绩。

复现入口为 `scripts/r34_candidate_stage.py`，完成结果为 `artifacts/r34-candidate/stage.json`；逐图与完整域记录在 `acceptance.json`，七对时间及模型、输入、二进制、源码哈希都在阶段结果中。不得覆盖这一完成 epoch 后重新挑选计时样本。
