# 16题：max57的精确前缀下界及局部整数规划负例

在已完整验收的Cinema新best上，进一步降低max需要改动前两级中的至少一级。固定这两级时，后面即使可任意选择确定性RGB8映射，也不可能把max从√57降到√56。本结论来自两个原色的精确碰撞和整数距离，不依赖优化器的失败推断，也不意味着整个四级模型族已经全局最优。

## 精确原色对

| 项目 | 原色A | 原色B |
|---|---|---|
| 输入RGB | (37,47,46) | (41,40,40) |
| 当前第1级后 | (53,48,41) | (54,50,41) |
| 当前第2级后 | (46,46,46) | (46,46,46) |
| 当前第3级后 | (48,45,36) | (48,45,36) |
| 独立四原表gold | (50,46,47) | (59,54,56) |

两个gold的平方距离是`9²+8²+9²=226`。对任何共同输出y，平方三角不等式给出`||a−b||²≤2(||a−y||²+||b−y||²)≤4·max(d²)`。226>4×56=224，因此二者不可能同时d²≤56；RGB8距离平方是整数，必有max²≥57。当前输出(54,50,52)恰使两者均为57，且此前完整16M验证已经给出全域max²≤57，故固定前两级的下界与实际完整域上界相等。

861行完整联合支撑中只有一个当前max57到达组，七种gold的半径平方56整数球交还独立穷举了252个候选，均不可行。原色代表由源RGB编号核对冻结gold NPY；前1/2/3级轨迹用独立Python任意精度整数、稳定坐标排序四面体重放。这里少量见证足以证明下界，完整域上界引用[前阶段](2026-10-24-cinema-arrival-budget.md)的独立四级/native验收；没有新跑全部照片。

见证的首级输出尚不相同，这给后续第2级研究一个明确方向，但不能据一对原色保证改变第2级必然成功。其他第一阶段不可区分组仍需检查，均值/p99和运行速度也必须另验。

## 局部MILP试验

在找出上述精确原因前，另冻结一次受限整数规划：当前104个正支撑节点每分量±2、0..255，共同移动不同parity，目标max²≤56。固定几何的Q16舍入以`−32768≤Σw·node−65536·y≤32767`精确建模；整数RGB差平方用相邻整数抛物线割线的上包络表示，在−7..7整数差上等于真实平方。双mean、双RMS、p99>12计数与固定√12阈值CVaR上界均不超过已验新best。范数初始使用26方向与当前误差方向支撑平面，若有候选才按真实误差添加合法外逼近平面。

有限合同覆盖262,144个half-up累加器、15个整数差平方、87,750个精确Cauchy不等式组合及一个已知可行m17小模型；独立uint64输出与solver整数y零差。真实模型含6,480变量、67,899约束、22,668范数支撑平面，SciPy/HiGHS首轮1.31秒返回infeasible、无incumbent。按冻结的最多4轮×20秒规则立即停止，没有扩盒、加时或反复重跑。

该浮点求解器状态本身只记录本次受限问题的负例，不当形式全局证明；上面的精确原色对才解释固定前缀为何无解。没有新候选、没有新native/照片/性能结果。`threads=1`由SciPy透传给HiGHS，原始“未识别但继续传递”警告完整保存，没有当成异常或隐藏。

环境Windows11 26200/Ryzen9 8945HX，Python3.12.14、NumPy1.26.4、SciPy1.15.2、Numba0.60；BLAS/MKL/OMP环境1，solver显式1线程，独立前向Numba4。上述1.31秒只指该离线求解阶段，不是图像处理速度。完整来源、参数和原件见[证据](../../report/data/p16-cinema-prefix-bound-followup-v1/README.md)。
