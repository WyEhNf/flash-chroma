# 以整数舍入区间推导局部混合的最小斜率

代理 `/root/tail` 按本会话用户授权，在κ=2局部负例之外另立冻结阶段。没有扫描斜率，而从两个训练max点的未舍入累加器推导最小整数κ，再仅对612支撑验证一次。推得κ=3、mask1/1，两原max点都跨过整数平台；这仍是局部可行性结果，未自动扩展完整域或性能。

Q16原/替代累加器为A0/Ad，令Δ=Ad−A0。想要某个RGB8通道输出q，需要整数权重w满足：

`q·2^32−2^31−65536·A0 ≤ Δw ≤ (q+1)·2^32−2^31−1−65536·A0`。

Δ为负时反向两端，得到精确weight闭区间，再代入 `w_c=min(65536,κ·t_c)`（t_c为该输出三轴到最近面的Q16距离）得到κ整数区间。仅枚举原/替代输出之间可能的整数RGB，筛到目标d²≤1681；取两点、mask1/2各区间的交与并，选最小正整数κ。所选κ和方向先保存到`derived-threshold.json`，之后才验证612色，不按其结果再改参数。

关键第一点(239,252,113)的blue A0=2504548，mask1 Ad=3126308，t=720。输出39需要w∈[1960,8867]，故κ∈[3,12]；κ2的w1440不足，κ3的w2160可行。第二点也存在共同κ3，最终两个点分别输出[246,255,39]/[246,255,42]。所有未舍入RGB累加器、分输出距离、可行RGB/weight/κ区间均保留，不能称为盲测参数。

合成区间合同覆盖5个含正/负/零Δ的夹具，各穷举65537个整数权重，核531个输出weight区间，并检查零距离/饱和映射边界，零差。这是整数公式正确性合同，不是实际κ参数扫描。

| 固定mask1/1的612支撑 | 原3e5f | κ3 |
| --- | --- | --- |
| 合并mean | 16.469943955 | 11.385613483 |
| 合并RMS | 19.791808565 | 15.118810514 |
| 合并p99 | 39.913796850 | 37.907650109 |
| 合并max | 41.012193309 | 40.012498047 |
| 合并CVaR最差1% | 40.317741684 | 38.441584934 |

两cell的mask1均值各自下降；原60图频率的这612色对全域mean贡献变化为−1.180612987e-6，d²>40数量减少119。NumPy uint64 Q32混合与逐项Python整数零差，原方向612色与945d完整流相等。局部结果不能直接冒充完整域max或百图结果；其他颜色、真实分输出面/相邻RGB8、原生支持、运行内存与速度50%底线尚未验证。

环境Windows11 26200/AMD64、Ryzen9 8945HX、Python3.12.14/NumPy1.26.4，OMP/BLAS/MKL环境1，仅NumPy/Python整数，无JIT/原生/性能调用。新bubble仍不是stock SLUT合同，官方许可未知。原κ2阶段保持不变。
