# 节点读取复用的受控实验

Agent：Codex；Operator：WyEhNf；状态：一次实验完成，性能未入围，仅本地归档，未PR、推送或升级默认。

本阶段保持已完整验收的3e5分输出坐标模型不变，只尝试减少AVX2内点读取。先分析地址，确认约96.42%的全色域颜色、96.49%的60张训练图像素具有相同的首末轴方向；固定Kodak03原始像素顺序的八像素整包中，约86.16%满足该条件。地址分类不映射颜色，也不能代表速度。

唯一候选在整个八像素包的三个输出方向一致时共用两个RGB内点读取，各输出仍用自己的Q16权重；其他包按原路径读取。共享坐标分支、RGB8逐级舍入、节点、侧表和线程分块不变。候选独立放在`experiments/channel-runtime-reuse`，没有改原CMake或此前已验收的运行时。新增构建、集中合同、固定计划及静态归档脚本供复现。

集中正确性合同覆盖m17/18/25/33混合四级、显式方向一致/不一致包、0与65536端点、非对齐、尾部与ABI输入；随后对唯一冻结模型做一次单级/等距四级的完整256³标量1线程、AVX2请求4线程比较，再核完整100张照片。全部与原独立整数oracle流逐字节相同，容量没有增加。四级后三张是cycleGBR/invertRGB/swapRG精确等距控制，不代表自然ISP。

唯一性能实验固定100张1024×768 RGB8、四级、预加载后的235929600字节输入；三个新进程串行，配置ABC/BCA/CAB轮换，1/4线程分别各五次完整图组。预热、SHA和IO在计时外，apply与copy+apply分列。没有拟合或其他数值任务并发。结果为完整图组的摊销ms/图，不能当作逐图延迟。
