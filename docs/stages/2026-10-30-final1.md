## 交付与实现

- [独立交付源码](../../submission/final1)：`main.cpp` 与单头 `flash_chroma_framework.hpp`，与服务器发布版本原字节相同。
- [分模块冻结源](../../experiments/final1)：十个实际生成源、上一交付入口与原 C++ 验收器。精度模块来源于历史迁移分支 `9a28cad4`，运行库来源于最新直接映射工作树（`e24525a0`），候选来自已有 prefix_joint 实验。精确来源以[原始 SHA 清单](../../report/data/final1-20261030/evidence/package-source-manifest.json)为准。
- [可移植打包器](../../scripts/package_final1.py)：从仓库来源重建两份源码，默认只比较；可输出到新目录。
- [归档核验器](../../scripts/verify_final1.py)：核对源码与服务器清单、原始证据及 Git blob，独立复算逐图/逐轮汇总。
- [证据入口](../../report/data/final1-20261030/README.md)：选择、全域、104 图、五轮计时、ABBA、输入 SHA 与服务器发布回执。

每次启动先读取四张原始 LUT；采样 33³，chain_ls 拟合末级，再按固定顺序优化第三级、第二级的整数节点（每级最多 32 节点、一扫）。搜索依据完整 RGB 域及原 LUT，使用真实后缀重放和 mean/SSE/p99/max/CVaR 保护；随后生成 DirectRGB24，逐像素使用查表核。没有把本批图片颜色、冻结模型或输出表硬编码进程序。

main 相对上一交付版本仅改变四处控制逻辑：17→33、默认数据目录为 data、增加可选 1..100 图片数量、循环使用该数量。[完整 diff](../../report/data/final1-20261030/evidence/main-vs-delivery.diff)已保存。参考映射、Delta 公式、TimeCost 边界及计时内 `out=img` 保持；旧 C++ 模板和其他工作树不变。PR 在 main 的新分支上新增独立包，不要求先合并 #103–#105，也不替换主库或历史交付入口。

## 服务器实测

i9-14900K，Ubuntu 24.04 / Linux 7.0.0-38，GCC 13.3；`g++ -O2 -std=c++17`，无全局 `-mavx2`、`-march=native` 或 OpenMP。单线程，公共 `~/locks/6.lock` 锁住物理 P 核 6，taskset 绑定逻辑 CPU 12；实际执行自动 AVX2 pair32。输入、源码、二进制身份与原始命令见回执。

| 完整域 SSE / p99 / max | 37,378,400 / 6 / 50.209560843 |
| 完整域最差 1% CVaR | 9.397557942 |

从原 LUT 重新拟合，四级模型逐字节等于冻结 prefix_nodes；完整 RGB8 输出也逐字节一致，并与原框架参考计算全域直方图。104 图结果复核通过。另行按题定命令编译 main 并实际执行四图，误差依次 1.467711、1.562505、1.592951、1.303775。

五轮实际 apply 的每图 fresh 输出及 `out=img` 在计时内；读图在前，原参考映射及两次 Delta 在后。正确性检查先于五轮计时，未额外调用 apply 预热。各轮均值为 0.972360、0.977920、0.975453、0.987877、0.950348 ms；报告保留全部 500 个原样本。

固定同一表地址与 pair32 核的 44 个 ABBA/A/A 样本中，chain33/prefix_nodes/geometry_output/history 中位均值约 0.93229/0.93039/0.93410/0.92990 ms。差异约 0.5%，小于本次 A/A 波动；不据此授予稳定速度优势，也不把该控制的 0.93 ms 替代正式 apply 的 0.975 ms。

拟合/搜索/Direct 准备观察为 **21.172590 秒**（8.271471 / 12.635237 / 0.264807）。读 LUT 为 7.451457 秒，参考表和初采样 0.334208 秒；均在 TimeCost 外。将这些单次观察按 100 图均摊并加映射中位数约 **290.56 ms/图**，这是组合估计，不是独立端到端实测。运行 arena 不是进程 RSS；原 LUT、参考表、搜索临时内存另计。
