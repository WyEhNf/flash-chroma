# 阶段说明：阶段 PR 交付与测试记录规范

本阶段按项目用户的明确要求补充 AGENTS.md，保留既有内容，将阶段交付方式和测试说明要求落为项目规范。

## 完成事项

- 阶段说明：要求每阶段记录目标、涉及方面、具体事项、主要文件和提交、结果与限制，并把说明保存在版本库中。
- 交付流程：阶段提交保留在工作分支，以 PR 提交给目标分支；不得直接提交或推送目标主干，也不得用仅 commit/push 代替 PR。
- 测试环境：按测试类型说明实际系统、硬件和工具链、构建参数、启用后端以及线程或设备，不适用或未执行环境单列。
- 测试目的：区分正确性、拟合精度、性能、数据/格式和文档检查，保存复现命令、判定口径、实际结果及证据，不扩大覆盖结论。

- 环境：Windows 11，PowerShell，Git 2.51.0.windows.1；独立工作分支 codex/stage-pr-testing-policy，基于 github/main 的 85f4a87。

- 方法：检查新增条款、核对 git diff --name-only，执行 git diff --check。
- 结果：条款核对通过；变更仅涉及 AGENTS.md 与本阶段说明；空白检查通过。
