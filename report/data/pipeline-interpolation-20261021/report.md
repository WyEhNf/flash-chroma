# 统一插值与四级分别匹配插值的精度、耗时对照

## 2. 四级流水线：实验设计

沿用已有研究三条固定数值链，共 12 个源，每条分别测试 17³、33³。它们是四级 RGB8 数值压力链；源色彩空间并未逐一认证，不能称为推荐摄影调色顺序。每一级使用不同 LUT，但允许不同 LUT 选择相同恢复算法；“逐级匹配”不等于强制使用四种不同插值。

各级从既有 `ls_tri_tri`、`ls_tetra_int`、`dp_supported`、`dp_jitter`、`curvature_int`、`jitter_tetra` 六种配置中，按旧实验 4096 像素/图的平均色差选最优。`ls_tri_tri` 对应三线性，其余对应四面体。选择记录在计时前写入 `evidence.zip` 内 `data/plan.json`。本轮不重新拟合，不按链输出搜索最优组合，也不把阶段 A 的坐标校准混入恢复器比较。

三组对照共用相同节点、网格、索引、Q16 分数表、级联顺序、每级裁剪和 floor(x+0.5) RGB8 舍入：统一四面体、统一三线性、逐级匹配。真值为四份冻结完整 LUT 依次直接查表；误差衡量最终输出与该真值的差异。

|链|顺序|17³ 拟合配置|33³ 拟合配置|
|---|---|---|---|
|1|Amber Haze → Arcade Dayz → Blow Me Down → Caramel Plum Cake|dp_supported → ls_tri_tri → curvature_int → curvature_int|dp_supported → ls_tri_tri → dp_supported → ls_tri_tri|
|2|1910s → 1920s → 1930s → 1940s|dp_supported → jitter_tetra → jitter_tetra → ls_tetra_int|dp_supported → ls_tri_tri → ls_tetra_int → ls_tetra_int|
|3|Grey Matter → December Greens → Emerald Malaise → Irish Uprising|jitter_tetra → jitter_tetra → dp_supported → dp_supported|ls_tri_tri → ls_tri_tri → dp_supported → dp_supported|
