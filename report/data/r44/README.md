组合策略相对 adaptive_bins 在9/180组改变训练指标，其余171组四指标相同；其中3个变化组属于最终输出恒定的径向阈值链，已明确单列。前置量化的两个非恒定训练源在m25/m33达到零误差。容量控制同时保留33/34箱在不足节点下的失败边界。[全部结果及解释边界](../../../docs/r44-new-policy-regions.md)。

这是四个新策略之间的描述性训练比较，不能替代全部13策略或留出评估。完整声明分母仍为7917项，留出输出未读取。
