# 数据扩展与合并阶段证据

对应 [合并数据集 v1](../../../datasets/problem16-unified-v1/README.md)与[机器可读验证](../../../datasets/problem16-unified-v1/validation.json)。本轮在第一批压力输入上继续追加数据，随后把原分类语料、历史控制、自然照片与两批压力输入接入统一索引。

- [第二批构造](extension-build.log)：36 个 case、43 张去重阶段源的哈希、21 张标准尺寸压力图，以及一组 151 色耦合回放。
- [合并构造](merged-build.log)：274 个 case、273 条不同有序源链、460 个图片别名、455 份不同 RGB 内容。旧五张 Kodak 保留别名，不重复计数。
- [完整图片审计](merged-audit.log)：455 个实际文件的 SHA-256、1024×768 RGB8 解码及 RGB 哈希通过；11 组压力图的像素多重集通过。没有重新读取数十 GB 的历史完整源表。
- [Python 正确性门禁](correctness.log)：28 项通过。新增扩展算术、原划分/队列合并、旧图恢复与拒绝覆写、耦合后端回放的回归覆盖。
- [导出和模型文件核对](export-and-artifact-check.json)：统一入口导出一条三维窄峰 case，四张源共 201,326,592 字节，43 色逐级完整查表与配方参考一致；12 个冻结模型文件哈希全部一致。
- [首次合并失败](merged-build-first-failure.log)：旧 CSV 包含 UTF-8 BOM，导致第一列名读取失败。已用 `utf-8-sig` 读取并加入回归断言，原 CSV 未改动；失败记录保留。

三组固定回放分别包含 43、43、151 个颜色，在当前 7 个编译整数后端上共执行 21 次原生映射，均相对独立整数 oracle 零字节差异。新耦合模型在 C99、结构化 AVX2 的调度中，第二级均选择通用 `tetra` 路径。它们是有限探针回归，不是本轮完整色域证明。

原 22 份受保护数值源码保持哈希一致，原 catalog、账本观测、冠军与 7,917 项计划未变。新增 62 个 case 仍为拟合质量未测，不自动继承历史图集资格或官方阈值。

已知源链、最终变换与图像哈希中，未发现训练/留出划分冲突；12 个历史 case 缺最终变换哈希，保留未知，不宣称完全无重合或统计独立。新 62 个完整源真值的哈希仅用于重复检查，不包含稀疏拟合误差评价。

环境为 Windows、Python 3.13.12、NumPy 2.4.6、Pillow 11.1.0，使用已存在的 MinGW 构建。本轮不重复 C++ 全色域验证，未运行方法/容量矩阵、预留源拟合质量、性能扫描或 Linux/Pixi、Docker、CUDA 验证。
