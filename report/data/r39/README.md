# R39 可核验记录

[原始证据归档](r39-evidence.zip)及[逐文件 SHA256](evidence-index.json)保留三个冻结模型、三个 CPU 后端、全部九项比较的 162 次计时、九组实际 100 图一致性核对，以及空闲状态、源码、模型、图像和二进制绑定。

正式判定使用九项双侧符号检验的 Holm 校正；bootstrap 区间为边际区间。新压力与 17 箱模型的结构 AVX2 相对普通 AVX2 配对加速分别为 1.96477 和 3.17268 倍，通用 clip 模型的差异未被证明。[完整口径及全部结果](../../../docs/r39-structured-performance.md)。这些是本机 16 线程批量映射数据，不是官方成绩或手机性能。

源码快照排除实时总账本、已有照片负载和 `report/data`。完整 LUT、图像及原生二进制不打包，记录保留必要哈希。
