# R40 可核验记录

[登记及补证归档](r40-evidence.zip)及[逐文件 SHA256](evidence-index.json)保存九条配对速度观测、精确模型/资源组、三个新增普通 AVX2 完整色域输出，以及三项实际被拒绝的错误元数据控制。六条新内核完整色域证明复用 R35，计时复用 R39；本轮没有新增拟合或速度测量。

逐 case 同时维护最小观测中位数、比较证实的最快项和耗时/模型内存 Pareto。压力与 17 箱模型已证实结构 AVX2 为组内最快，clip 组仍未决。跨模型、图像、资源或基准时期不合并，未测量的 case 不填推测速度。[选择规则与结果](../../../docs/r39-structured-performance.md)。

源码快照不复制实时总账本；本轮已完成的不可变登记记录独立归档。完整 LUT、图像及原生二进制不打包。
