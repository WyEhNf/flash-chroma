# 68个LUT最佳模型的联合差分存储分析

本报告使用既有best-per-lut选择，不重新拟合或重算精度。差分方案均要求逐字节恢复原SLUT节点。

- 模型数：68；网格分布：{'17': 3, '33': 65}。
- 原始SLUT总量：7,340,492 B。
- 仅按组件SHA去重：7,157,288 B。
- 整包zlib-9：5,189,078 B（离线包体，不是热路径容量）。

## m17

3个模型节点原始44,217 B；最小生成树精确差分44,217 B；节省0 B（0.00%）。
其中真正采用位压缩差分的边数：0/2。

## m33

65个模型节点原始7,007,715 B；最小生成树精确差分6,781,390 B；节省226,325 B（3.23%）。
其中真正采用位压缩差分的边数：26/64。

## 结论

- 如果最小生成树仍接近原始节点容量，说明跨LUT相关性不足以抵消解码和随机父依赖。
- zlib适合下载包或磁盘归档；运行时应在加载时一次性解压回普通SLUT，不应在每像素插值时解码。
- 组件SHA去重与共享不可变对象没有逐像素代价，应优先于差分热表示。
