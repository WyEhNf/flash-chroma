# R43 可核验记录

[ROM 部署验收归档](r43-evidence.zip)及[逐文件 SHA256](evidence-index.json)保留两套生成的 C99 数组／头文件／来源清单、编译和运行凭据、四个 freestanding 目标的对象头信息，以及首次缺少查看工具时的真实失败记录与旧驱动。原生执行文件和目标对象不打包，保留其哈希。

两套编译后的 ROM 数组与原四表字节相同，各执行一次完整 256³ 色域并与 R35 原生输出相同。实际三线性模型被明确拒绝。首次像素核对成功后，仅恢复对象检查，没有重复像素执行。[接口、内存口径及实际验收范围](../../../docs/r43-rom-export.md)。

本轮不测速度，也不把交叉编译当作实体手机运行；没有改变四级独立映射、C99 核心或拟合算法。源码快照排除实时账本、原始语料和已有照片负载。
