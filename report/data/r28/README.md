# R28 数据与账本阶段证据

200条独立四表链、320张内容唯一的标准合成图、23组探针已完成物化和完整审计。所有链均检查256³整数串联真值；完整对象内容去重后47,714,402,304字节。199种不同最终变换，12条常量最终输出已标记；重复组为两条轴置换回归控制，留出最终真值未与训练重复。

本阶段完成数据与持久账本基础设施，不代表5400候选矩阵、类别sweet zone、实际100图新模型资格或移动端部署已完成。图像均为synthetic。官方数据和阈值未知。

大体积原始对象与图片位于被Git忽略的`data/corpus-v1/`，小型归档保留清单、内容哈希、检查结果、生成器与可复现源码。后续策略运行会继续追加账本；R28结束时历史观测为9源70份，其后新增观测由R29单列记录。
