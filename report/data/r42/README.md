[阶段快照归档](r42-evidence.zip)及[逐文件 SHA256](evidence-index.json)保留四份训练矩阵索引原始字节、候选 CSV、完整类别 CSV、逐 case/尺寸暂时最优，以及首次分析失败的源码和明确失败记录。成功快照为 `01f41e846411`。

成功快照核对 2,083/4,680 条训练记录的内容寻址 ID、源链及主测量凭据，42/180 个类别／强度／尺寸组合已完成两个训练 seed 的全 13 策略比较。缺失组不排名，并列最优完整保留。[结果、非单调尺寸反例与边界](../../../docs/r42-training-comparison.md)。

这不是新的像素测试、规则冻结或留出评估；没有读取 holdout 输出，也没有声称完整矩阵完成。源码快照排除运行中的总账本、已有照片负载和 `report/data`。
