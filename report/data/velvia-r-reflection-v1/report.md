# 唯一R轴反射的匹配拟合负结果

Agent：Codex；Operator：WyEhNf；日期：2026-10-19；状态：按预声明门槛停止，未提交、推送或PR。

这次只检验一条有明确几何依据的路线：反射R轴，改变四面体的体对角线，看看是否更适合Velvia中跨通道裁剪的形状。在同一物理网格、同一完整RGB8原表和同一均匀未舍入L2目标下，唯一反射方案没有改善：连续矩MSE由标准划分的1.8526704487157986升到2.816171668979223，恶化52.006077%。

预先冻结的触发要求是至少下降20%，即MSE不高于1.4821363589726388。该方案未触发，因此没有评价原32768+16探针，没有生成折回SLUT，没有原生映射、新完整域输出、100图或性能测试。没有改换G/B反射、其它对角线或更弱比较基线。

## 对比如何保持公平

参考原表SHA为`6c4387352bd0845ce597f13dca32f2f808b39439d06ce78b4881922a4fc294b7`。原2dd模型SHA为`2dd467b040a4ed25f9000e7debd085af4a07f08d780be2fbcd156c9aa8118947`，原离线grid SHA为`1b62bbc42278fc9deb993e1dc3b1c1973fbc9a47aa7e108d891c51cec26d2eb3`。原33³网格和权威坐标逐值核对一致。

在R反射域r'=255−r中，参考表是`T'=T[::-1,:,:]`，派生权威表严格取：

```text
gridR'        = 255−gridR[::-1]
idxR'(r')     = m−2−idxR(255−r')
fracR'(r')    = ONE−fracR(255−r')
G/B的grid、idx、frac保持原值
```

反射只是完整色域中的一一置换，原参考RGB平方和完全相同，完整域均匀目标也保持相同测度。它改变四面体划分而不扩大节点数量。比较对象是matched阶段对标准划分求得的同目标连续LS，而不是原2dd的不同mean/尾部/照片目标。

反射域idx与有效坐标`idx*ONE+frac`先核非降，再直接把这些派生权威表传给原始矩C ABI。没有由浮点grid重生并替换权威表，也没有在降序折回表上组装。运行后仅作静态计数，理想镜像grid再生表与派生表本例idx/frac均为0差异。若将grid元数据转float32，最大变化7.62939453125e−6；权威表仍单独保存，不能把近似元数据当作另一套实际坐标。

## 实际拟合和完整域矩

唯一原始uint64矩组装覆盖16777216色、实际4线程。目标平方和仍为`[401381165656,372708601024,406395407002]`；常量设计总量`sum(diagonal)+2sum(upper)=N*ONE²`用Python整数核对。原始矩SHA为：

```text
f5ff3ad7dd20ae504a9695b7350e96fd61b8a2711ff627ab9d104da1eeb9af9a
```

反射后的参考表数组SHA为`0b380beacad822dc3b386bd22963216da5889aec1c12eddacb90d8d22e87df51`，反射域轴表SHA为`64965b0f664baf7cd1cb773fa18ae0a640b8d921f81335382b25318bd651d2e7`。与原设计不同的矩身份是预期行为。

互异最近RGB见证的整数支撑证书通过，最小两倍对称余量为80466，完整域缩放H的正定下界为6474777156/2⁴⁰。此证书只说明当前设计正定，不说明精度优秀。

原始矩按同matched缩放转为float64：`H=Hnum/2³⁸`、`b=bnum/2²²`，不加ridge。已有matched连续节点沿R反序后仅作暖启动，每通道各调用一次Jacobi预条件CG，rtol=1e−13、最多1000迭代。实际如下：

|通道|迭代次数|info|相对残差|
|---|---:|---:|---:|
|R|25|0|4.9434598e−14|
|G|24|0|9.6572511e−14|
|B|25|0|6.0902908e−14|

三通道均达到冻结的1e−12相对残差要求，没有追加求解或改预算。连续节点范围为−14.0688912至257.4920492，其中14415个通道越出RGB8。它们是不可部署的连续LS向量。归档内的RGB8节点只按clip+half-up派生，用于保留明确量化控制的参数，并没有执行其前向或宣称整数最优。

连续全域MSE从完整正规矩计算，不生成全域输出。该浮点矩目标及残差没有包含舍入区间，应解释为近似LS诊断，不称严格最小值证书；本阶段也没有借用旧固定坐标的有理下界证明本反射模型无解。
