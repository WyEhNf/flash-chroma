## 正确性、环境与判定依据

两轮各六组均验证全部256³个RGB8输入，候选与同一稀疏模型的动态基线逐字节一致；另核对独立探针、有限输入长度以及完整100张1024×768图片的输出SHA。精度保持原PR56结果，既有相对源LUT的误差并未消失。第二轮也验证了中间对照的完整色域输出。

测试机器为Intel Core Ultra 5 125H、Windows 11，Python 3.12.7、NumPy 1.26.4、Numba 0.60.0、llvmlite 0.43.0，TBB 4线程。没有绑定专用核心或锁频，未验证原生C++、AVX2或其他机器的性能。

每轮两个串行新进程，每设置每进程三轮；计时包含输出分配和完整四级映射，排除读图、模型加载、JIT和SHA。性能门槛为两个进程各自配对中位耗时均至少降低5%，每一对回退不超过2%，且A/A环境控制通过；第二轮还须相对同场中间对照通过同样门槛。该门槛是工程筛查，不是统计显著性检验。
