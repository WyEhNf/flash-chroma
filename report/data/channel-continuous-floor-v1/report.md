Agent：Codex；Operator：WyEhNf；状态：冻结三次组装及连续诊断完成，未部署新模型、提交、推送或PR。

当前3e5几何下，一次单节点±1和一次2³节点同号±1的局部收益很小，并不等于节点已经接近全局最优。本轮固定同一个3e5模型的所有shared idx和三输出各自权威frac，只改变离线连续节点变量。三个输出各完整组装一次原表均匀L2的整数矩、各解一次无ridge正规方程，结果仍有明确连续空间：当前RGB8节点未舍入MSE为2.57789472265；无界连续LS约1.84708523234；把该连续点clip到合法[0,255]后，精确Q20连续可行点MSE为2.14577819321，比当前低16.7624%。这个连续点不是RGB8节点，不是可部署模型，也没有证明照片或原加权真实RGB8距离能获得同等收益。

## 精确证书与范围

没有沿用旧几何的正定证书。原grid的最近RGB8见证在三个新权威设计上分别检查一次，对称Gershgorin整数余量77683/70936/64779，均为正；独立见证坐标/索引/权重/余量已保存。它们证明各自完整设计SPD；若失败本来只能说充分证书失败，不能当秩亏，本轮没有搜索其它见证。

为避免依赖SPD，主结论使用合法节点盒[0,255]的一阶凸性下界。令Q=2^16，原始矩整数Hnum/bnum来自同SHA C ABI的Q16外积和，故其精确二次型PSD。F=||Az-y||²/64，H=Hnum/2^38、b=bnum/2^22。证据点z=zint/2^20，其中zint通过float.as_integer_ratio后精确half-up取得。定义gnum=Hnum*zint-bnum*2^36，Fnum=zint·(gnum-bnum*2^36)+c_raw*2^72，则F(z)=Fnum/2^78。对任意合法连续节点x，凸性给F(x)≥F(z)+2(Hz-b)·(x-z)。逐坐标把线性项在0或255取最小，精确MSE下界为：

`[Fnum + 2Σgnum*(choice*2^20-zint)] / 2^96`，gnum≥0时choice=0，否则255。

三输出相加所得严格有理下界：

`146335093803017038629881354575 / 79228162514264337593543950336` ≈ 1.8470085530087952。

矩乘、独立二次型交叉核、线性最小化和Fraction比较全部使用Python任意精度整数。float64 H/b转换、CG、残差norm只提供证据点，不作为严格下界。原生uint64矩的常量守恒逐路成立，三个完整域覆盖回执均为256³；原始矩与实际轴表全部保存，可独立复算。

作为辅助，三个成功SPD证书还给无界LS的精确残差下界约1.8470852322663618；对应精确Q20可行点提供上界，间距见`rms-rational-corollary.json`，因此浮点解的近似程度也有独立整数依据，不把单纯浮点残差当证明。

合法节点的凸四面体连续输出始终在[0,255]。若最终RGB8所有色精确，则每通道连续误差至多0.5，总MSE至多3/4；主下界大于3/4，故该冻结几何不可能通过合法节点实现完整域RGB8零误差。反三角给最终RGB8 RMS≥sqrt(MSElower)-sqrt(3/4)，浮点展示约0.4930215。另以精确有理平方比较MSElower>(1359/1000)^2且3/4<(867/1000)^2，严格得到最终RMS>123/250=0.492；此推论不依赖浮点展示。

这不是当前模型接近理论最优的证据。已保存3e5最终RGB8完整域RMS为1.64829403583，只作为历史上下文；本阶段没有重映射。下界也不适用于其它坐标、其它算子、无界节点再clip的输出函数，不提供mean/p99或照片下界。
