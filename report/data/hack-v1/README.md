# hack-v1 数据完善与有限回放证据

对应 [数据集定义](../../../datasets/problem16-hack-v1/README.md)及[验收口径](../../../datasets/problem16-hack-v1/acceptance.json)。本轮完善数据，不启动完整拟合矩阵或性能扫描，不修改旧的 7,917 项计划与历史结果。

- [阶段环境与结果](../../../datasets/problem16-hack-v1/validation.json)：Windows/MinGW 已有构建，Python 3.13、NumPy 2.4.6。Linux/Pixi、Docker、CUDA 本轮未测。
- [构造日志](build.log)：26 个 case、35 张去重完整源的字节哈希、14 张标准尺寸压力图、2 组小型回放。
- [数据审计](inspection.log)：四组输入多重集、100 张自然照片哈希及回放记录核对通过。源字节在构造阶段流式哈希，没有在审计阶段重复全量生成。
- [统一 Python 门禁](correctness.log)：25 项通过，包含三项小型新增回归；没有重复 C++ 全色域或运行压力拟合矩阵。
- [单 case 导出](export-check.json)：四张共 201,326,592 字节的合法完整源 LUT 已导出到本机忽略目录，文件哈希全部一致，43 个颜色的逐级查表参考一致。
- [热点输入](hotspots-input.json)及[热点转图核对](hotspots-check.json)：已有固定颜色见证转为 45 个唯一邻域颜色和三种同多重集图片；原 JSON 被保留。这不是全色域最坏颜色报告。
- [两张标准图片的原始核对记录](competition-ppm-check.json)：PPM 输入经过比赛尺寸/RGB8 合同和 C99 四级入口，运行时相对独立整数 oracle 的差异均为 0 字节。

常规 CI 仅增加确定性小回放；m17/m33 的两个方法、预留参数的拟合、扰动敏感性、全色域精度及性能比较均未执行。反例没有全局最小性证明。
