# 软件gather与固定坐标排序的静态停止证据

[阶段说明](../../../docs/stages/2026-10-20-skylake-scalar-gather-static.md)解释目标、真实环境、模型边界及停止原因。候选只构建和反汇编，未加载、未做有限整数/完整色域/百图/MCA/性能，不进入服务器四方案矩阵。

`analysis.json`按全部被调函数核对两个固定四级循环：实验SIMD对象硬件gather为零，却每8像素调用四次transform，静态预算1402/1456条。`analysis.zip`保存全部原始汇编、初步清点、最终静态回执和实际分析源码。`build-*`及`built-not-executed.zip`保存冻结源码、库、对象及依赖；参考两对象与既有修订5逐字节相同。

同一回执检查固定a399侧表的589824个轴对比较，三对输出通道均存在严格排序反转，保存最小遍历顺序下的轴对反例及RGB(1,210,0)的坐标。它只否定无条件共用排序的前提，不声称已经验证某个错误共享输出或拟合不稳定。`decision.json`明确未执行范围。
