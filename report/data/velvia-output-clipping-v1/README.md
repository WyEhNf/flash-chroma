# 输出裁剪相关性归因归档

只读原2dd已保存全域输出、原表和60训练图完整频数。内部输出组占照片69.642%像素、73.531%距离误差；端点+邻饱和占30.358%像素、26.469%误差。没有照片mean主要误差集中在剪裁附近的证据，本轮停止以clip-aware为双mean主路线，不生成候选。

[报告](report.md)、[冻结计划](plan.json)、[运行身份](run.json)、[结果](results.json)、[清单](manifest.json)记录完整口径。groups.csv提供两测度三组的数量、mean/RMS、距离误差和、>3/>7贡献；channel-residuals.csv提供6种参考端点通道条件的all/gt3/gt7同通道/其它通道拆分；group-histograms.npz保存完整组内平方距离整数直方图。measured-source.zip保存实际脚本、计划和依赖。

cube尾部与端点/近饱和存在关联，暗部R/B部分尾部由同通道残差主导；高端G/B条件的尾部大多在其它通道。不能把关联当因果、内部输出当陡变，或据此承诺非线性/clip-aware能改善。不同通道条件有重叠，不能直接相加其像素或整体误差；报告明确哪些按分量SSE可以相加。

来源SHA、原60图分组与频数hash核对，旧cube mean/RMS和统计守恒通过。0模型前向、0图片解码，未拟合、扫描、新模型/全域映射、百图或性能比较，未改核心/根driver或提交推送PR。大表/旧输出/频数文件不随精简归档重复保存，需要计划中原路径的同SHA输入复现。没有官方或SOTA结论。
