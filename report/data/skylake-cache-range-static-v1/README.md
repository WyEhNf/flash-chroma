# 范围判断简化的静态停止证据

[阶段说明](../../../docs/stages/2026-10-20-skylake-cache-range-static.md)给出数学前提、指令语义、实际环境、停止理由及未执行范围。参考对象与上一阶段已验组合逐字节相同，候选没有加载或执行。

`plan.json`与`build-*`绑定当前构建、源码与两库；`analysis.json`保留两处循环全部数据，`diagnostics.zip`保存原始汇编、MCA输出、实际分析脚本及生成器，未裁剪失败或不利信号。原始含空格日志只在ZIP中保存。`built-not-executed.zip`保存两库和对象，不把构建成功标为运行通过。

候选各少13条指令、gather保持15，但一处模型周期增加2.11%，另一处下降5.44%，吞吐下界仅改善约1.2%，故`decision.json`明确`stop_static_not_adopted`。没有有限整数/完整域/100图/性能结果，也无Linux或Skylake实测。`initial-design.json`为原提议，最终未运行的边界合同改用非零R最小值和不对称G/B范围，二者不是实测结果。

数学证明只适用于当前构造器的全节点R界及合法Q16/RGB8。参考及已验组合保持原样，不把本原型纳入服务器默认矩阵；后续须先完成数值验收再考虑真实性能。
