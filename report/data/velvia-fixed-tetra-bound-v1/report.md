## 整数矩和正定下界

令N=2²⁴，Q=2¹⁶，A为N×33³的权威四面体权重矩阵，Y为原RGB8表。每行权重非负且总和为1。把三个输出通道合在一起，定义：

```text
F(Z) = ||AZ−Y||²_F / 64
H = AᵀA/64 = Hnum/2³⁸
b = AᵀY/64 = bnum/2²²
c = ||Y||²_F/64 = c_raw/64
```

`jshc_full_normals_v1`返回diagonal、7条正向stencil上三角、rhs与目标平方和。依据已审计ABI，逐项最大值分别不超过2⁵⁶、2⁵⁶、2⁴⁸及每通道2⁴⁰，uint64不会溢出。原输入每个R码属于唯一R cell，同奇偶R cell写互不相交节点平面，两个奇偶遍历合计覆盖全部N色。

本次一次组装的原始整数矩SHA为：

```text

```

它与matched阶段完全一致。元数据为`[16777216,4,32,1,401381165656,372708601024,406395407002]`，实际4线程。另以Python整数验证`sum(diagonal)+2sum(upper)=NQ²=72057594037927936`，三个目标平方和与旧记录一致。没有先转float64矩再计算本次证据。

正定证书也独立重建：为每个节点选择最近RGB8色，共35937个互异见证，使用独立标量排序得到整数四面体权重方阵Bq。其行和均为Q。若d为对角、r/c为行列和，则对称部分的整数余量为`4d−r−c`。本次全部行最小值为81423，与旧证书一致。因此：

```text

H ≥ (Bq/Q)ᵀ(Bq/Q)/64
lambda_min(H) ≥ 81423²/[64(2Q)²]
              = 6629704929/2⁴⁰
```

所有余量、行列和、权重与索引均用整数计算；没有使用浮点特征值估计。`witness-certificate.npz`保存每个见证输入、四个索引/权重及所有余量，能够独立检查。

## 精确有理残差界

每个旧float64系数先用`float.as_integer_ratio()`取其精确二进制有理值，再half-up到Q20，得到`z=zint/2²⁰`。随后全部矩乘、对称二次型和残差平方使用Python任意精度整数。

令k=6629704929：

```text
gnum = Hnum·zint − bnum·2³⁶
g = Hz−b = gnum/2⁵⁸
Fnum = zint·(gnum−bnum·2³⁶) + c_raw·2⁷²
F(z) = Fnum/2⁷⁸
F* ≥ F(z)−||g||²_F/lambda
MSE* = 64F*/N
     ≥ (k·Fnum−4sum(gnum²))/(k·2⁹⁶)
```

这里g是目标梯度的一半；二次函数恒等式`F(z)−F*=gᵀH⁻¹g`给出所用残差界。它不依赖z已是精确最优解。代码另从上三角逐边计算二次型，与矩乘结果核对；还用独立Fraction缩放核对最后闭式，全部相等。

实际整数证据为：

```text

sum_gnum²     = 7369942832237043967535475530
Fnum          = 146783675396703516201395718788

```

## 为什么能推出RGB8零误差不可能

对[0,255]节点，非负守恒权重使未舍入输出也在[0,255]内，不需要裁剪。若最终half-up后的每个RGB8通道都等于原表整数标签，则舍入前每通道与标签的差的绝对值至多0.5。因此每个像素的连续平方RGB距离至多3/4，全域MSE也必须至多3/4；这与上述严格下界矛盾。RGB8节点只是[0,255]节点的子集，结论同样适用。

对任意合法节点，舍入改变量的全域RMS至多sqrt(3/4)，三角不等式还给最终RGB8全域RMS不小于`sqrt(MSE_lower)−sqrt(3/4)`。约0.49510297只是浮点展示。无需浮点开方也能给较保守的严格结论：有理数比较验证`MSE_lower>(136/100)²`且`3/4<(87/100)²`，所以最终RGB8全域RMS严格大于0.49。
