# 固定分通道坐标后的单轮节点精化

Agent：Codex；Operator：WyEhNf；状态：按冻结计划完成，最终候选未入围，未提交、推送或PR。

本阶段只检查一个明确问题：3e5候选的独立分通道坐标冻结以后，再允许共享RGB8节点各输出分量各改一次±1，能否带来至少0.5%的双mean额外改善。结果只有cube选择mean下降0.1127%、照片选择mean下降0.1207%，两个p99均未变化，没有达到门槛，按计划停止。不能据此称已有坐标与节点全局最优，只能说明这一次固定次序的±1有限邻域收益很小。

## 实际方法与身份

新增`python/lutlab/channel_nodes.py`、`scripts/run_channel_nodes.py`、`scripts/verify_channel_nodes.py`，冻结计划为`experiments/velvia-channel-nodes-v1.json`。没有修改既有分通道坐标、原生、核心或默认路径。

起点为`artifacts/velvia-channel-coordinates-v1/channel-coordinates.npz`，SHA256 `3e5f8fd94e8dc9b97dbfea2823896b8dffb6e014b5e6056ab5c10b58a69af3d0`。grid/shared_idx/channel_frac保持逐元素不变；只改变886个节点输出分量，各自最大偏移1。输出仍为实验NPZ扩展表示，不伪装SLUT v1，不代表官方认可。

直接复用此前冻结的完整256³ RGB8训练行、原Velvia完整表标签及质量：0.48全域均匀、0.48原60图完整频数、0.02边界、0.02旧热点。没有重新解码照片，没有把两图归因的audit反例或其重复次数加入训练。逐色caps完全沿用`max(49,旧2dd误差平方)`，包括零质量行；标签始终原单级LUT，无残差或复合标签。

按输出R/G/B依次构造各自固定四面体设计，然后每输出依次处理节点坐标parity0..7，共24块恰好一次。每节点当前通道只允许±1，在当前另外两个输出误差不变时，计算真实half-up RGB8距离`rho=sqrt(d²)+.02*max(sqrt(d²)-6,0)^2`的条件收益。单个通道8色各一次之后不回头追加。每块内同色正支撑互斥，各分片私有归约；三通道不能共用I/W。每次只常驻一个通道设计I/W，实际536870912字节，尚有RGB缓存、d²、质量与训练数据；没有据此声明总内存不变。

训练加权目标0.9269145401466254→0.9262197464054988。24块预测与实际收益最大差5.202e-16，逐色cap违规0，最终fresh RGB前向与缓存/平方距离完全一致。训练完整域fresh核对只用于缓存与约束验证，没有保存新cube输出流或完成完整精度验收。
