# R31 AArch64大小端实际模拟执行

QEMU10.2.1用户态模拟器在WSL Ubuntu26.04 x86_64运行静态AArch64大小端ELF。直接链接R30冻结的C对象，嵌入同一模型字节，壳层仅提供Linux write/exit和内存辅助函数。所有嵌入模型故意非对齐。

3组历史模型×2端序×快捷/通用两路径，共12个完整RGB8输出流，全部SHA与既有实际原生结果相同。宿主增量哈希，不保存600MiB原始输出。共201326592次颜色求值。

这是模拟器执行正确性；实体ARM设备、NEON性能、手机功耗均未测。QEMU以Ubuntu包SHA核验后解压到被忽略的本地工具目录，未安装系统包或注册binfmt。核心库不含测试壳的系统调用汇编。归档保留构建/执行命令、源与对象/ELF/模拟器SHA；工具二进制和ELF需按记录重建。
