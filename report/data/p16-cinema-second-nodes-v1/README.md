# Cinema第二级两候选完整质量与旧87资格

本阶段保留完整16777216输入无损联合支撑拟合、两独立全域四级uint64/原生/100照片验收、独立原始流审计、旧87调色板资格与整数前缀球交证书。结果为精度通过、综合best尚未升级：实际输出336/380色超过8位direct容量，新16位运行时及吞吐是后续研究。

- `evidence.zip`：完整小原件、模型、计划、实际执行源与所测旧87 DLL；每成员SHA在manifest，CRC与原字节均核对。
- `fit-summary.json`、两份 `*-accuracy.json`：完整域、合并照片及100逐图的原件，不隐藏局部恶化。
- `independent-audit.json`：从原始RGB流独立重算整数直方图/指标及SHA。
- `palette-eligibility.json`：旧87 cache603/703色、实际输出336/380色，无受控性能。
- `prefix-bound.json`：新max50热组的49球交均可行，未找到固定前缀50下界，不能称已全局最优。
- `source-identity.json`：实际工作区执行字节与原HEAD对照，继承CRLF/LF差异如实保留。
- `execution-receipt.json`：实际退出码、有限合同及临时GBK诊断失败说明。
- `quality-tiers.json`：ZIP封存后单独从冻结JSON算出的六档精度代理，含全部1224项记录、输入SHA及执行源SHA；不在早先ZIP/封存publication-audit的成员范围，提交前另按实际Git blob核对。相对共同a399，max_first过100精度档、p99_first过90精度档，速度仍待测。

大参考、输入与可重放RGB输出保留本地，路径和SHA在manifest。环境、命令、取舍和未完成事项见 [阶段说明](../../../docs/stages/2026-10-24-cinema-second-nodes.md)。Git暂存与提交后仍须逐blob核验，不能用ZIP核验代替。
