### 使用方法
1. 推荐使用vscode+Gcc编译器进行编码和调试
2. 验收环境使用Gcc编译版本为mingw-w64(x86_64-13.2.0-release-posix-seh-ucrt-rt_v11-rev0)
3. 根据自己熟悉的编程语言类型选择C或者C++工程
4. 根据编译器安装路径修改.vscode下面的json文件指定到本地安装目录  
"miDebuggerPath": **"D:\\tools\\mingw64\\bin\\gdb.exe"**  
"command": **"D:\\tools\\mingw64\\bin\\g++.exe"**  
"detail": **"compiler: D:\\tools\\mingw64\\g++.exe"** 
5. 当前工程通过Terminal-Run Task选择Gcc编译生成exe文件，可以直接运行
### 编程说明
1. 选手需要完成lut_sparse和apply_3d_lut两个函数的编程。
2. LUT文件夹下的Test1.3DL是线性LUT表，可用于调试测试使用，验收的时候不会使用。

## 使用约束
1. 不允许使用多线程并行加速方法；
2. 考虑验收环境的环境一致性，不使用NPU、GPU硬件进行加速；
